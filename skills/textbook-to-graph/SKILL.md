# 教材一键转知识图谱（Textbook → Knowledge Graph）

## 1. 定位与业务痛点

一本 600 页的教材，学生平均要花数小时才能回答「这本书的骨架是什么、该按什么顺序学」；
教师做一份数字化课件要人工摘录章节与术语。本技能把 AstralPath 验证有效的
**「PDF → 抽取 → 结构化 → 图谱 → 出题素材」流水线**沉淀为可复用工作流：

| 阶段 | 做什么 | 人类类比 |
|---|---|---|
| **抽取** | 文本层直读优先，OCR 只补空页/坏页；页眉页脚剥离、阅读顺序重排 | 扫描仪 + 校对员 |
| **结构化** | 章节识别、术语抽取（AC 自动机）、实体融合（「RNN/循环神经网络」归一） | 编辑做目录与索引 |
| **构图** | TextRank 选核心概念 + PMI 连边 + 依赖句式 → 无环 DAG + 学习路径 | 教研组长排教学顺序 |
| **出题** | 从原文句子生成带来源页码的题目素材（可追溯、防编造） | 命题老师 |

**确定性边界（红线，不可违反）**：

- **LLM 不产生事实**：章节、术语、边全部由算法（词频/共现/句式）计算得出；
  LLM 只在最后一步做「题目措辞润色」，且每题必须携带来源页码，无来源不得出题
- **图谱必须无环**：DAG 收尾是硬闸，带环图谱禁止输出（先修关系成环即逻辑错误）
- **不臆造依赖**：边只有三种来源——同章共现（PMI）、目录层级（chapter→term）、
  依赖句式正则（「先学 X」「以 X 为基础」）；禁止模型自由发挥「我觉得 A 依赖 B」
- **扫描书诚实降级**：无 OCR 引擎时输出「仅目录骨架图」并明示，不假装完整

## 2. 输入与输出

### 输入

| 字段 | 说明 | 默认 |
|---|---|---|
| `pdf_path[]` | 一个或多个教材 PDF（文本层 / 扫描版均可，中文优化） | 必填 |
| `max_terms` | 每书保留的核心术语上限 | 24 |
| `pages_sample` | 建图前抽样校验的页数 | 24 |
| `ocr_engine` | `auto`（文本层优先）/ `paddle` / `rapid` / `off`（仅文本层） | auto |
| `lang` | 主语言；本管线中文优化，非中文退化为目录骨架图 | zh |

### 输出

| 产物 | 内容 | 质量闸门 |
|---|---|---|
| `extract.json` | 逐页文本 + 来源（text_layer / ocr）+ 可读字符数 | 每页可读字符 ≥40，不足页标记 |
| `graph.json` | `nodes[]`（chapter / term 两类）+ `edges[]`（prerequisite / belongs_to / refers_to），含无环证明 | 节点 ≥10 且边 ≥5；DAG 校验通过 |
| `mindmap.json` / `mindmap.md` | 思维导图树（章节为干、术语为叶） | 章节覆盖原文「第 N 章」命中 ≥80% |
| `quiz_draft.json` | 题目素材：题干、选项、答案位置、**来源页码**、`why` | 无页码引用的题一律丢弃 |

## 3. 四阶段工作流

> 阶段有严格依赖：1→2→3→4。禁止跳过 1 直接「看目录编图谱」——那是臆造。

### 1. extract-text（阶梯式抽取）

1. **文本层试探**：先按文本层直读（pdf.js / PyMuPDF），统计每页可读字符；
2. **坏页判定**：`detect_needs_ocr` 标记空页/乱码页/图片页，仅对这些页起 OCR；
3. **OCR 阶梯**：扫描页走 PaddleOCR（首选）→ RapidOCR（备选），页级并行；
4. **清洗**：页眉页脚剥离（跨页重复行检测）、TSV 行聚类还原表格、多配置投票修复、
   双栏阅读顺序重排、混淆字修复（白名单保护代码标识符，避免 `1`→`l` 腐蚀变量名）；
5. **验收口径**：抽样 `pages_sample` 页，可读字符 ≥40 即通过（12 本实测 6.8k–21.2k 字符/本）。

### 2. structure-doc（章节与术语）

1. **章节识别**：「第 N 章 / N.1 / Chapter N」标题模式 + 页首行密度锚定（页密度闸）；
2. **术语候选**：AC 自动机匹配已知词表 + n-gram 频次候选新词；
3. **实体融合**：并查集 + 有界 Levenshtein 归一同义词（大小写、中英混写、连字符变体）；
4. **门槛**：章节命中率 <80% 时降级为「目录骨架图」并明示（诚实标注，不硬编）。

### 3. build-kg（无环 DAG 与学习路径）

```text
节点 = 章节(chapter) + TopN 术语(term)        # TextRank 窗口共现得分排序
边   = belongs_to（章节→术语，目录层级锚定）
     + refers_to（术语↔术语，PMI 共现，低频偏置校正）
     + prerequisite（依赖句式正则：先学/基于/前提/需要先掌握…）
收尾 = DAG 校验：发现环 → 断开 PMI 权重最小边 → 复检 → 通过才输出
布局 = 分层（ longest-path 层级）+ 学习路径 = 拓扑序（同层按 TextRank 降序）
```

- 速度口径：**<0.1s/本**（12 本实测），可交互、可批量；
- 术语超 `max_terms` 按得分截断，落选术语不丢弃——写入 `graph.json` 的 `overflow[]` 供人工复核。

### 4. draft-quiz（可追溯出题素材）

1. 逐章节取「术语定义句 / 列表句 / 对比句」（句式规则定位），LLM 仅做措辞；
2. 每题强制字段：`source_page`（页码）、`source_quote`（原文短句）；
3. 判分必须是确定性匹配（选择/填空答案唯一），禁止让模型现场判分；
4. 输出给题库后，可无缝接入同生态 **knowledge-debt-repair** 技能：
   `graph.json` 的 nodes/edges → `kp_nodes/kp_edges` → 知识债诊断 → 14 天修复计划。

## 4. 质量闸门汇总（任一失败即降级并明示）

| 闸门 | 条件 | 失败动作 |
|---|---|---|
| 完整度 | 抽样页可读字符 ≥40 | 标记坏页；整本 <60% 通过 → 建议换 OCR 引擎重跑 |
| 章节 | 「第 N 章」命中 ≥80% | 降级目录骨架图 |
| 图谱规模 | 节点 ≥10 且边 ≥5 | 输出空结果 + 原因（不硬凑） |
| 无环 | DAG 校验 | 断最小 PMI 边重试 ≤3 次，仍环则拒绝输出 |
| 可追溯 | 每题有 source_page | 无页码的题直接丢弃 |

## 6. 验证证据（截至 2026-09-28，AstralPath v2.2.0）

- **12 本真实教材 MLP 验收**：OCR 12/12（文本书文本层直读、扫描书自动全页 OCR）；
  图谱 12/12（30–51 节点 / 47–133 边，建图 <0.1s/本）；`docs/mlp-acceptance-2026-09-28.md`
- **13 本 6,720 页全量**：2,519 节点 / 2,662 边；产物 `kg-deep-test/*.mindmap.{json,md}`
- **引擎横评**：PaddleOCR vs RapidOCR 平行基准（`tools/bench_ocr_engines.py`）、
  `tools/ocr_regression.py` 12/12 PASS
- **算法回归**：图谱 + OCR 84 项；全量门禁 235+ 项 ALL GREEN（`scripts/verify_all.ps1`）
- **深度优化已落地**：full 全书透传、流式进度、表格抽取（管道/空白对齐/TSV→Markdown）、
  SQLite 题库去重、术语质量闸、构图缓存

## 7. 故障降级预案

| 故障 | 现象 | 预案 | 口播一句 |
|---|---|---|---|
| 无 OCR 引擎 | 扫描书抽不出字 | 目录骨架图 + 明示「正文未数字化」 | 「先给骨架，装好引擎再补全文」 |
| 加密/损坏 PDF | 打开失败 | 跳过并列原因清单，不中断批量 | 「坏的单独报，好的照出」 |
| 术语爆炸 | 候选 >500 | 按 TextRank 截断 + overflow 落盘 | 「先保主干，细枝在附件里」 |
| 建图成环 | DAG 校验失败 | 断最小 PMI 边 ≤3 次，仍环拒绝输出 | 「有环的图谱是错的，宁可不发」 |
| 非中文教材 | 英文/小语种 | 退化为目录骨架图（中文优化边界） | 「中文书是主场，其他书给骨架」 |
