# 账户 · 教材今日任务 · OCR 优化

## 1. 根据示例教材生成今日任务

示例 PDF（Kotlin / Python / C# / Java / Go / 深度学习 / 大模型 Agent 等）已接入：

1. 藏书阁「导入示例资料」或 账户页「导入并解析示例教材」
2. OCR/文本层解析 → 章节 + 关键词 → 自动识网
3. 生成今日任务：concept（章节框架）+ drill/quiz（关键词桥接）

接口：

```text
POST /v1/materials/seed-samples?parse=true
POST /v1/materials/parse-all?ocr=quick
GET  /v1/materials/{id}/tasks?maxTasks=6
GET  /v1/materials/today-from-books?maxTasks=8
POST /v1/students/{id}/today          # 会并入教材任务
POST /api/v1/auth/material-today      # 登录账户拉取
```

当前样例：Kotlin 教材可生成 6 条任务（章节概念卡 + 关键词练习）。

## 2. OCR 优化

`tools/ocr_pipeline.py` v2：

- 章节标题缩短（「第1章讲解了…」→「第1章 安装…」）
- 领域词典（编程 / 深度学习 / 会计）
- 扫描版并行 OCR（2–3 worker）
- OCR 文本清洗
- 输出 `suggestedTasks` / `sentences`

## 3. 用户账户（参考 GalReview）

| 能力 | 接口 |
|---|---|
| 注册 | `POST /api/v1/auth/register` |
| 登录 | `POST /api/v1/auth/sessions` |
| 当前用户 | `GET /api/v1/auth/me` |
| 更新资料 | `PUT /api/v1/auth/profile` |
| 改密 | `POST /api/v1/auth/password-changes` |
| 退出 | `POST /api/v1/auth/logout` |

演示账户：

```text
demo@astralpath.local / demo123456  → 绑定 demo-student-a
teacher@astralpath.local / teacher123
```

UI：顶栏「账户」→ 登录/注册、绑定演示学生、拉取教材今日任务。
