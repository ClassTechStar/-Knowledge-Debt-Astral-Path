# 教材真题题库（依据示例 PDF 正文）

题目来源：用户提供的示例教材 **正文/目录抽取**，不再使用「这是本章主干概念」类元问题。

## 题库覆盖

| 题库键 | 教材 | 题数 | 示例考点 |
|---|---|---:|---|
| kotlin | Kotlin编程实践 | 4 | 语言定位、Multiplatform、Scoop、IDE |
| python | Python从入门到实践第3版 | 4 | 多重赋值、常量全大写、学习笔记项目 |
| deeplearning | 深度学习入门 / 花书 | 4 | 动态类型、感知机偏置、逻辑门、np.dot |
| nlp | 深度学习进阶 NLP | 5 | 先学习后推理、model.params、软语言、word2vec |
| csharp | C#从入门到精通第7版 | 4 | 类是对象模板、表达式、string.Remove |
| go | Go语言从入门到精通 | 4 | var 初始化、类型推断、if-else 示例 |
| java | Java从入门到精通第6版 | 4 | 字节码可移植、成员/局部变量、main |
| agent | 大模型应用 AI Agent | 4 | Agent 定义、工具调用、OpenAI client |

文件：`eval/textbook-questions.json`

## 接口

```text
GET  /v1/question-banks
GET  /v1/materials/{id}/textbook-questions?maxTasks=6
GET  /v1/materials/today-from-books?maxTasks=8
POST /v1/students/{id}/today
```

今日任务优先输出 **教材真题**（source=`textbook-question-bank`）。

## 使用

1. 打开 `http://127.0.0.1:5190/`
2. 藏书阁导入示例 / 或直接「今日」→「教材任务」
3. 按教材切换解析后，题目会匹配对应书目的正文知识点
