贝叶斯优化、遗传编程等都是进行 NAS 的方法，其中最有前景的候选方法是强化学习。强化学习的 NAS 热潮是由一篇题为 "Neural Architecture Search with Reinforcement Learning"[39] 的论文引发的。该论文通过强化学习自动优化网络结构，成功地发现了与人的设计同等优秀甚至更好的架构。下面简要介绍一下该论文的方法。
该论文的核心思路是，神经网络的架构可以通过"文本"指定。下面是一个将神经网络的架构指定为文本数据的示例。不过这是一个虚构的格式。
graph {
    node {
        input: "Input1"
        output: "Result ReLU"
        op_type: "Relu"
    }
    node {
        input: "Result ReLU"
        input: "Input2"
        output: "Output"
        op_type: "Add"
    }
    ...
}
另外，使用 RNN 可以生成可变长度的文本。理论上，也可以考虑使用输出上面这样文本的 RNN。综上所述，可以考虑使用 RNN 作为智能代理，在强化学习的框架下寻找最佳架构，如图 10-14 所示。
