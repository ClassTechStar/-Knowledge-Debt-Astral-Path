## 3. 质量三算
- **速度**：avg 1192 ms/页，0.84 页/s，样页 avg 380 字符。全书 OCR 需 ~15 分钟。
- **CER vs 文本层**（n=21，word级）：mean **0.0175**；worst5：p247=0.1483（矩阵公式）、p332=0.1356（图9.15标签）、p179=0.0653（图6.3旋转标签）、p100=0.0053、p587=0.0038。纯文本页基本为 0。
- **CER vs rapid3 全书参考**（n=21）：mean **0.0064**，charDelta 合计 **+72**（本次略多）。worst2：
  - **p247**（cer 0.0898）：前 200 字对比——
    - 文本层：`…我们可以线性回归的情况下简单说明这种区别：| |18|5|15|−9|−3| |y∈Rm|=|4|0|0|−2|…`（矩阵元素按列向量+括号片逐字排列）
    - 本次OCR：`…我们可以线性回归的情况下简单说明这种区别：|18] 0 0 -2 0 0 2|5 0 -1 0 3 0 3|15 0 5 0 0 0 0 -2 (7.46)|-9 1 0 0 -1 0 -4 -5|…`（列向量元素被拆散混入矩阵行，行序错乱）
  - **p146**（cer 0.0228）：OCR 比参考多 44 字符（如多出 `distribution)，p(`），属识别模型小差异，无实质内容损失。
- **公式区损失量化**：最密公式页 p247 原始字符 1107→927（**-16.3%**），CER 0.148 约为纯文本页（≤0.005）的 **30 倍以上**；损失构成=大括号定界符（文本层 116 个 PUA 片，OCR 全丢）+ 矩阵行序错乱 + 下标归并（L1→L¹）。图内旋转标签（p179 y 轴、p332 Channel coordinates）进入不了检测框或碎裂。

## 7. 结论
本书文本层完整可信（word 级 CER≈0.018），Round B 的 text_layer_full 路线（78.3 万字符/21.9s）正确且不可超越；OCR 仅需对 8 页兜底。**唯一系统性风险是公式密集页的矩阵结构**：若下游知识抽取需要公式语义，OCR/文本层均只保留碎片化的字符流（文本层括号片为 PUA 私有区编码），建议对含矩阵/求和公式的页面（如 p247 类）按 formula 区域特殊处理或保留原文裁图。
