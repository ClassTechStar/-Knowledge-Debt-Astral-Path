## 4. CER 三算（项目 `cer()`：去符号归一化后 1−SequenceMatcher）

### a) vs 文本层（15 个有文本层样页）
- 平均 **0.1042**；最差 5 页：

  3. p156 0.113、p211 0.0701、p42 0.0648
- 纯正文样页（61、93、106、137、144、277 等）CER 多在 **0.004–0.035**，逐字质量高。

### b) vs rapid3 全页参考（17 个非空白样页）
- 平均 **0.0447**，总字符差 **-42**（OCR 略少）；最差 2 页：
  - p230 0.4855 — 前 200 字对比（mine / rapid3）：
    - mine：`7.2 卷积层 205 / 1 2 3 0 / 1 2 0 1 / 0 2 3 15 / 3 0 1 2 0 1 2 / 2 3 0 1 1 0 2 …`
    - rapid3：`7.2 / 卷积层 / 205 / 1 / 2 / 3 / 0 / 2 / 0 / 1 / 0 / 1 / 2 / 3 / 15 …`（逐数字一行）
  - p167 0.0814 — mine 将分式节点顺序合并成行（`∂y/∂x` 打散），rapid3 更碎但与文本层序更近。
- 结论：本样 OCR 与参考引擎高度一致，偏差集中在**图形/公式页的行序**，非识别错误。

### c) 公式符号专项
- 文本层几乎不含 ∑、∂、σ 等数学符号（15 页合计仅 3 个）；OCR 输出 32 个（p167 一页 21 个）——即**文本层本身丢符号，OCR 反而重建更多**。
- 但分式的上下结构（分子/分母/上标）在 OCR 中被压平成一串，二维结构不可恢复；且 `cer()` 剥离非 \w 符号，**CER 指标会系统性低估公式损失**。

## 7. 缺陷清单（详见 A-report.json）

1. **formula / p167 / medium**：分式与计算图二维结构线性化丢失，公式页 CER 抬升（全书普遍风险）。
2. **figure / p230 / medium**：整页数字矩阵图 OCR 顺序与排版序不一致，网格结构丢失（vs TL 0.875）。
3. **blank / p25 等 7 页 / low**：needsOcr 标记对空白页误报，管线可预筛空白页跳过 OCR 省时。
4. **garble / p33、p42 / low**：文本层自身含 U+FFFD（6/3 个），OCR 输出正常——缺陷在文本层。
5. **other / p13 / low**：目录点线/页码依赖归一化才可比，直接用 OCR 原文解析目录页码会失败。

## 8. 结论

本书管线质量良好：无内容性缺页，正文 OCR 与文本层近乎逐字一致；主要损失集中于**二维公式/图形页的结构**，且现有 CER 归一化会低估该损失；空白页可预筛提速。
