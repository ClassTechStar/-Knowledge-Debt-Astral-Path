## 1. 一句话结论

全书 290 页**全部是纯图扫描、零文本层**；Round B 的 21,536 字符 100% 来自对**前 28 页**的 OCR（max_ocr=28 截断），只拿到全书内容的 **6.5%**；全本 OCR 约需 9 分钟即可恢复约 **30 万字符（13.9 倍）**，且实测质量优秀（vs 参考 CER 1.16%）。

## 4. OCR 实测与三个口径的对拍

样页统计：n=18，**avgMs=1835.4，pages/s=0.545，avgChars=1033.6**。

### a) vs 文本层 —— 无法计算（n=0）
文本层 jsonl 290 行全部 0 字符。这不是抽样问题，而是**本书根本没有文本层**，cerVsTextlayer 记 n=0。

### b) vs rapid3 全页参考（n=18）
- **平均 CER = 1.16%，中位数 0.26%**，无 error 页，charDelta=+131（基本持平）。
- 最差 5 页：p289=4.50%（书封内嵌文字）、p250=4.43%（对话体换行合并）、p155=3.66%（整页控制台长标识符）、p46=3.21%、p72=2.33%。
- 6 个样页 CER=0.000（如 p102、p173、p17）。

### c) vs 视觉真值（加分项）
- p150：CER=**0.50%**（gtChars=1029 / hyp=924；OCR 在代码行前幻觉出 `In ` 前缀）。
- p250：CER=**3.07%**（2451/2439，多为段落换行/合并差异而非字符错）。
- 证实 OCR 输出真实可靠，rapid3 参考可作可信基线。

### 覆盖率量化（本轮核心疑案）
| 项 | 数值 |
|---|---|
| Round B extractedChars | 21,536（rapidocr 28/28 页，即第 1–28 页） |
| 该 28 页的 rapid3 参考字符 | 22,214 → Round B 覆盖了这 28 页的 **96.9%**（被截断页内部质量尚可） |
| rapid3 全本 | 331,792 字符 → Round B 全书覆盖率 **6.5%** |
| 丢失部分 | 第 29–290 页，262 页 / 309,578 字符（**全书 93.3%**） |
| 全本 OCR 外推 | 1,033.6 × 290 ≈ **299,747 字符** = Round B 的 **13.9 倍** |
| 全本 OCR 耗时 | 290 ÷ 0.545 页/s ≈ **9 分钟**（参考引擎约 15.6 分钟） |

**建议**：对 zeroText=100% 的书，max_ocr 截断应解除或按剩余比例上调；本书是 12 本中对拍价值最大的案例。
