## 3. OCR 质量三算

### 3.1 速度与产量
- 平均 **1950 ms/页**，**0.513 页/s**（868 页全 OCR 约 28 分钟），平均 534 字/页，样页合计 10146 字。

### 3.2 OCR vs 文本层（15 个有文本层样页）
- 均值 CER **0.2624**；最差 5：p690(0.837)、p625(0.645)、p415(0.571)、p401(0.429)、p327(0.320)。
- **重要解读**：前 4 名高 CER 不是 OCR 差，而是文本层残缺——如 p690 文本层仅 72 字，OCR 从代码截图多提出 901 字。这是"有文本层但内容不全"的直接证据。正常文字页 p250(0.002)、p700(0.000)、p2(0.030) 几乎零差异。

### 3.3 OCR vs rapid3 参考（19 页）
- 均值 CER **0.0564**，总字数 10146 vs 参考 10179（**charDelta = -33，-0.3%**）→ 与 Round B 结果高度可复现。
- 最差 2 页前 200 字对比：
  - **p1（CER 0.315，封面）**：参考"作同大/十年辆/打造经典…"vs 本次"十年晒/打造经典/27小时微课视频讲解…"——立体书影艺术字乱序+错字，封面固有难度。
  - **p860（CER 0.224，高密度代码页）**：两版前 200 字几乎逐字相同（`strModuleTag != '450°)|I …`），差异集中在后段代码易混字符（l/1/I、O/0）与换行合并方式。

### 3.4 视觉真值加分项
- **p700：CER vs GT = 0.000**（500 vs 501 字，纯正文页零差异）。
- **p300：CER vs GT = 0.364**——正文部分逐字一致，缺口全部来自章首**思维导图**：GT 含【思维导图：…控件概述/选择类控件(ComboBox/CheckBox/RadioButton…)…】完整描述，OCR 只得到破碎片段。

## 7. 结论

1. **正文页质量极好**：纯文字页与视觉真值/参考几乎零差异（p700 CER=0），无 PUA/FFFD，无水印倾斜，管线可复现性高（vs rapid3 均值 CER 5.6%、字数差 -0.3%）。
2. **最大风险是图片化代码**：13.7 万字（34%）内容缺口集中在零文本整页代码截图簇（755-773、836-868）与 85 个"正文+代码截图"页——必须走图片 OCR 通道，代码块建议更高 zoom 或专用代码 OCR + 后处理。
3. **结构缺口**：无目录页、仅 1 个"篇"标题成行、章首思维导图内容丢失；章节锚点需 chHeadPages+正则校正，广告页（p1/p4/p868）应过滤。
4. 全 OCR 成本可接受：0.513 页/s → 868 页约 28 分钟。
