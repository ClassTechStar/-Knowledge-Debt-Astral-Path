## 7. 缺陷清单（详见 A-report.json defects，共 17 条）

最严重 3 条：
1. **missed_content（high，全书级）**：纯文本层丢 36.9% 内容，代码图整块丢失（p421 文本层 0 字 vs 实际 832 字）。
2. **missed_content（high，样页 p421/482/547/609/239/494）**：零文本或仅标题碎片的图片化页面，样页 OCR 证明可完整找回。
3. **code（medium，p300 等）**：代码图 OCR 符号保真差（`[]`、`;` 易丢），影响代码复用。

其余：order（p32/365 导图标签乱序、p600 环绕图插段，low）、garble（p600 CABUT/CAA、☑ 丢失，low）、other（目录启发式 tocLike 漏报 + 无页码，low）。

## 8. 结论

1. RapidOCR 引擎本身**优秀且可复现**（vs rapid3 mean CER 0.0085、字符差 +10；vs 真值 0.004–0.04）。
2. 本书瓶颈不在 OCR 而在**文本层混排缺口**：必须走文本层 + OCR 融合管线，纯文本层会丢约 37% 内容（代码章最重）。
3. inventory 的 tocLike 与 suspRatio 启发式在本书全部空转，选样应依赖零文本/低字数信号；目录需按文本层回填 p16–32。
4. 代码图 OCR 需后处理（符号校正）才可用于代码抽取场景。
