# 混沌演练（§24）

脚本按**先演练环境、后生产**的顺序执行，且每个脚本都写明**预期结果**与**回滚动作**。

| 脚本 | 注入故障 | 预期结果 | 回滚 |
|---|---|---|---|
| `pod-kill.sh <svc>` | 删除一个 Pod | Service 不中断；PDB 保底 1 副本；30s 内恢复 2/2 | 自动（Deployment 重建） |
| `db-outage.sh` | 数据库缩容到 0 | `live` 仍 200、`ready` 转非 200；接口返回明确错误不崩溃 | 脚本内自动恢复 |

**安全约束**
- 仅在 `NS` 指向演练命名空间时执行；生产请先确认变更窗口与回滚预案。
- 不在业务高峰执行；一次只注入一类故障，便于归因。
- 演练前后各记录一次基线指标（错误率、P95 延迟），用于判定是否达标。
