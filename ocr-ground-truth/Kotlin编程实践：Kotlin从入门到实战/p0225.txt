11.2 重复执行lambda表达式问题如何多次执行给定的lambda表达式。解决方案使用内建的repeat函数。讨论 repeat函数位于标准库中。它是一个接收两个参数的内联函数。这两个参数为一个Int类型的用于表示迭代次数的数字，以及一个用于执行操作的（Int）->Unit类型的函数。当前的实现如示例11-4所示。示例11-4：repeat函数的定义@kotlin.internal.InlineOnly public inline fun repeat(times: Int, action: (Int) -> Unit) {     contract { callsInPlace(action) }     for (index in 0 until times) {         action(index)     }} 该函数执行指定的lambda表达式指定的次数，将当前迭代的从零开始的索引作为参数。示例11-5给出了一个简单的用例。示例11-5：使用repeat fun main(args: Array) {     repeat(5) {         println("Counting: $it")     }
