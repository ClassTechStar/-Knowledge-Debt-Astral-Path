1.9 使用Gradle构建Kotlin工程问题如何使用Gradle构建一个包含Kotlin的工程。解决方案为Gradle添加额外的Kotlin插件，并在编译时添加Kotlin JDK依赖。讨论 1.7节与1.8节中的示例展示了如何将Kotlin插件添加到Gradle中。本节将介绍如何向构建文件中添加一些函数以处理你项目中的Kotlin代码。要在Gradle中编译Kotlin代码，你需要在Gradle构建文件中的dependencies块中添加一些东西，参见示例1-14。示例1-14：使用Kotlin DSL构建一个简单的Kotlin工程（build.gradle.kts） plugins {     `java-library`                    ➊     kotlin("jvm") version "1.3.50"    ➋} repositories {     jcenter()} dependencies {     implementation(kotlin("stdlib"))  ➌} ➊ 从Java库插件中添加任务。 ➋ 将Kotlin插件添加到Gradle中。 ➌ 在编译时将Kotlin标准库添加到工程中。
