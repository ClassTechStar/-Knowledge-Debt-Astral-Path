3.5 操作符重载问题在本书中，operator在大部分情况下译作“操作符”，但是在特指加法、减法、乘法、除法、位运算等涉及数学计算的时候，译作“运算符”，理论上来说“操作符”包含“运算符”。如何让调用者能够对库中定义的类使用+和*等操作符（运算符） 。解决方案使用Kotlin的操作符重载机制来实现相关函数。在Kotlin中，许多操作符（包括加法、减法和乘法）都作为函数来实现。当你使用+、–或*等符号讨论时，实际上都委托给了相关的函数。这意味着通过提供这些函数，你可以允许调用者使用操作符来调用这些函数。参考文档中给出的经典示例是为Point类提供成员函数unaryMinus，参见示例3-13。示例3-13：在Point类中重载unaryMinus操作符（摘自参考文档） data class Point(val x: Int, val y: Int) operator fun Point.unaryMinus() = Point(-x, -y) val point = Point(10, 20) fun main() {    println(-point)  // prints "Point(x=-10, y=-20)"}  在覆盖除了equals（双等号）以外的操作符时，operator关键字是必需的。如果你想将相关函数添加到并非由你编写的类中怎么办？可以使用扩展函数来完成这项工作。包括add、subtract以及multiply。在Kotlin中，+、–以及*运算符对应于函数plus、minus以及例如，考虑Apache Commons Math（Java）库中的Complex类，它代表一个复数（一个包含实部和虚部的数字）。如果浏览Javadocs（https://oreil.ly/TMhLd），你将看到这个类包含的方法
