6.3 管理无限序列问题如何获取无限序列的一部分？解决方案使用返回null的序列生成器，或者使用诸如takeWhile的序列函数。讨论序列与Java中的流类似，都拥有过渡操作或末端操作。过渡操作返回一个新的序列，末端操作返回任意其他值。当你在序列上通过函数调用创建了一个流水线时，在进行末端操作之前不会有数据通过序列。示例6-7中展示的函数firstNPrimes计算从2开始的前N个质数。此处展示的示例使用了示例6-6中给出的并在6.2节中讨论过的nextPrime函数，为方便起见，在这里重复给出： fun nextPrime(num: Int) =     generateSequence(num + 1) { it + 1 }         .first(Int::isPrime) 该序列使用了节中的isPrime扩展函数。重复一次，你无法提前知道要检查多少个质数才能找到质数，因此序列是解决问题的自然方案。示例6-7：寻找前N个素数 fun firstNPrimes(count: Int) =     generateSequence(2, ::nextPrime)  ➊         .take(count)                  ➋         .toList()                     ➌ ➊ 从2开始的质数无限序列。 ➋ 过渡操作仅检索请求的计数。 ➌ 末端操作。生成的序列是无限的。take函数是无状态的过渡操作，它返回仅包含第一个计数值的序列。如果你简单地执行这个函数但不在最后调用toList函数，将不会进行质数计算。你所拥有的只是一个序
