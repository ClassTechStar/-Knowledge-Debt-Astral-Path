## 4. Android WebView 薄壳（完整代码）

`MainActivity.kt` 要点（请生成完整可编译文件）：
- `AppCompatActivity` + `Theme.AppCompat.Light.NoActionBar`（防闪退）
- `WebView` + `hardwareAccelerated` + `LAYER_TYPE_HARDWARE`
- `WebSettings`：js、domStorage、wideViewPort、loadWithOverviewMode、`textZoom=100`、`FontFamily` 回落 `sans-serif`
- 加载 `assets/www/index.html`（与 Web 同字节）
- 离线旗标注入：`window.__ASTRALPATH_OFFLINE__=true`（连不上 API 时用本地核心）
- `AndroidManifest`：INTERNET、usesCleartextTraffic、largeHeap

`app/build.gradle.kts`：minSdk 26、versionName 1.5.0、release 签名 keystore（alias/pass 告知团队）。

**性能**：包体目标 ≤50MB；本方案 WebView 壳实测约 2.8MB。冷启动 ≤2s。
