## 2. 禁词表 banned_words.json（完整清单）

```json
{
  "crisis": ["自杀","不想活","轻生","结束生命","自残","伤害自己","跳楼","上吊","割腕","suicide","kill myself","end my life"],
  "shame": ["蠢","笨","废物","没救","不可救药","垃圾","傻子","弱智","白痴","loser","stupid","idiot"],

  "sensitive_domains": ["crisis","sensitive","semantic","family_income","religion","health_diagnosis"],
  "fallback_template": "这段内容暂时无法展示，请查看教材原文或联系老师。"
```

规则：
- 命中 `crisis` → 只返回 `agent.crisis`，转人工，**不评价学生**。
- 命中 `shame` / `punish` → 改用 `fallback_template`。
- `sensitive_domains` 永不进画像标签、永不给教师看。

## 3. 隐私与授权口径（一页纸）

**教师可见**：班级聚合薄弱点（人数≥3 才显示）、已授权学生的债边（匿名学号后四位）、计划完成率。
**教师不可见**：危机相关记录、敏感域标签、未授权学生任何明细、可定位到个人的自由文本。
**学生权利**：随时 opt-out；opt-out 后个性化推荐与标签立即停用；可导出 JSON / 一键清空。
**文案**：统一「未获得授权」；不得写「你被监控」「老师会处罚」。

## 4. 演示脚本

### 4.1 三分钟版（可照念）

> 各位好，我是知债：星穹学途。学生最怕的不是努力，而是不知道自己哪里没学懂——前面欠一口，后面全听不懂。
>
> 我们只做四步。第一步诊断：系统找出「会计等式 → 借贷记账法」这样的红边，就是知识债。第二步计划：14 天补课表，每天不超过 40 分钟。第三步练习：做题，系统记住你会不会。第四步销账：连续两次小测合格，债就还清，界面上会显示「已销账」。
>
> 所有数字都由本地公式算出，AI 不能改分；隐私上教师看不到敏感标签。谢谢。
