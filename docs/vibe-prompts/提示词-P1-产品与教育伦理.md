### 3.3 语气规则（AI 生成文案时必须遵守）

1. **一律陈述 + 建议**，禁止第二人称指责：不许写"你必须""你怎么还""你为什么总是"。
2. **不说绝对化的负面判断**：不许"你完全不会""你彻底没掌握"。改成"这一项还需要再练两次"。
3. **数字只描述来源**，不解释好坏：写"掌握度由本地公式算出"，不写"你的分很低"。
4. **空态也要有温度**：不要只写"无数据"，要写下一步能做什么。
5. **错误提示不甩锅给用户**：写"这段内容暂时无法展示，请查看教材原文或联系老师"，不写"你操作错误"。

## 4. 交付物 ②：禁词表与危机词表（JSON）

### 4.1 `banned_words.json`（羞辱 / 恐吓 / 处分 / 敏感域）

```json
{
  "shame": ["蠢","笨","废物","没救","不可救药","垃圾","傻子","弱智","白痴","loser","stupid","idiot"],
  "punish": ["处分","开除","退学","记过","通报批评","留校察看","劝退","勒令退学"],
  "sensitive_domains": ["crisis","sensitive","semantic","family_income","religion","health_diagnosis","身份证","银行卡密码","详细住址"],
  "fallback_template": "这段内容暂时无法展示，请查看教材原文或联系老师。"
}
```

**规则（写进文档，P2 会照此实现）**：
- 命中 `shame` 或 `punish` → 整句替换为 `fallback_template`。
- 命中 `sensitive_domains` → 该字段永不进画像标签、永不给教师看、永不写进日志。
- 命中判定用「归一化后包含匹配」：全角转半角、繁简折叠、忽略大小写、忽略空白（与 P2 的 `PatternSet.Normalize` 一致）。

> **注意**：仓库里已存在一份旧文件 `src/AstralPath.Mobile.Offline/AstralPath.Mobile/Assets/banned_words.json`，当前内容只有 `["处分","开除","退学","记过","通报批评","留校察看"]`。
> 你交付的**新版本要覆盖它**，并同步通知 P2（因为 P2 的代码读的是这个路径）。

## 5. 交付物 ③：隐私与授权口径（一页纸）

按这三栏写，写成表格：

| 栏目 | 内容（**逐字采用**） |
|---|---|
| **教师可见** | 班级聚合薄弱点（同一薄弱点人数 ≥3 才显示）；已授权学生的债边（匿名，只显示学号后四位）；计划完成率。 |
| **教师不可见** | 危机相关记录；敏感域标签（家庭收入 / 宗教 / 健康诊断 / 身份证 / 银行卡密码 / 详细住址）；未授权学生的任何明细；可定位到个人的自由文本。 |
| **学生权利** | 随时 opt-out（关闭个性化画像）；关闭后立即停用个性化推荐与标签；可导出全部数据为 JSON；可一键清空；导出不含任何他人数据。 |

**统一话术**：未授权时一律显示"**未获得授权**"。
**禁止话术**：不许写"你被监控""老师会处罚""不上报就……"。

补充两条硬规则：
- **k-匿名**：教师视图里任何一个聚合数字，样本 <3 时**直接不显示**（显示"样本不足"而不是显示"1 人"）。
- **最小必要**：教师视图只显示薄弱点名称和人数，不显示具体是哪几个人。

### 6.1 三分钟版（**可照念，约 450 字**）

```text
各位评委好，我是「知债：星穹学途」。

学生最怕的不是不努力，而是不知道自己哪里没学懂——前面欠一口，后面全听不懂。
我们把这种"前面欠下的账"叫知识债。

我们只做四步。

第一步，诊断。系统从教材里自动建出知识图谱，找出「会计等式 → 借贷记账法」
```

## 11. 常见坑（提前看，能省两小时）

| 坑 | 表现 | 怎么避 |
|---|---|---|
| resx 键重复 | P4 界面上出现错字 | 生成后让 AI 跑一遍"列出重复键" |
| JSON 多了逗号 | P2 那边解析直接崩 | 一定用 `python -m json.tool` 验证 |
| 文案里写死了数字 | 违反"数字只能算出来"红线 | 用槽位 `{impact}` `{score}`，不要写 0.86 |
| 危机回复加了安慰以外的句子 | 违反伦理红线 | 危机回复**只能那一句**，一个字都不加 |
| 忘了覆盖旧文件 | P2 读的还是旧表 | 覆盖后立刻通知 P2 |
| 写了"你必须……" | 指责语气 | 改写成"建议先……" |
