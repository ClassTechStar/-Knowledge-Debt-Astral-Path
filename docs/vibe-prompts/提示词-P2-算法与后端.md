## 3. 核心公式（权威）

### score-v2
```text
score = min( 0.50*know + 0.30*retention + 0.20*prereqSupport , 0.55 + 0.45*min(prereq) )
know   = 0.85*(successes+0.5)/(attempts+1) + 0.15*(meanConf/5)
retention = exp(-ageDays / S)
S = 2.5*(1+0.45*streak)*(1+0.25*ln(1+attempts))
prereqSupport = 0.35*mean(prereq) + 0.65*min(prereq)
// 无先修时 prereqSupport=0.5，Ceiling=1.0
```

### impact-v2
```text
sigmoid(x)=1/(1+exp(-x))
impact = 0.55 * sigmoid((sf-0.55)*8) * sigmoid((0.50-st)*8) * w * cross
       * (1+0.12*ln(1+downstream)) * (1+0.08*ln(1+freq))
cross = 1.0 | 1.15
hit := freq>0 && impact>=0.08
```

### sale-v2
```text
weighted = 0.7*acc + 0.3*(conf/5.0)
meets := weighted>=0.65 && acc>=0.7 && conf>=3
streak' = meets ? streak+1 : 0
attempts' = attempts+1
cleared := streak'>=2 && attempts'>=3
状态: Open -> Repairing -> Cleared(终态)
```

### K1–K5 / PlannerBuilder / QuestionScheduler / Graph / OCR / Profiler
按下列签名实现（逻辑已定）：

- `PlannerConstraintChecker.Check(items, dayBudget, openRefs, skipped)` → 违规码 K1–K5
- `PlannerBuilder.Build(goals, titles, horizon=14, budget=40)` → 0/2/6 间隔，core/challenge 分层
- `QuestionScheduler.Priority(q)` = `(1-score)^1.2 * (impact+0.05) * exp(-4*(d-(score+0.15))^2) * (1+age/14)`
- `GraphTopology`：TopologicalOrder / Layers / CriticalPath / Bottlenecks(源点割) / DownstreamMass
- `GraphInference.TextRank` + `Pmi(co,a,b,N)=max(0, log2(co*N/(a*b)))`
- `GraphLayout.Layered`：x=layer，同层重心排序；`Crossings()` 计数
- `LearningPath.Order`：`2.5*block + 1.5*critical + layer + pagerank`
- `OcrTextEngine.FixConfusions/FilterNoise/ReconstructCjkLines/ReconstructFromTsvWords/VotePasses/Score/Refine`
- `ReadingOrder.Sort`：XY-cut 两栏
- `UserProfiler`：Brier / CalibrationBias / Extract / Style / Topics / Smooth / TeacherView / PrivacyNoise / SoftNudge
