## 4. 核心算法实现细节（逐文件）

### 4.1 `Algorithms/MasteryCalculator.cs` — score-v2

```
score = min( 0.50×know + 0.30×retention + 0.20×prereqSupport ,
             0.55 + 0.45×min(prereq) )
know          = 0.85×Empirical(attempts, successes) + 0.15×(meanConf/5)
Empirical(n,s)= (s+0.5)/(n+1)                        ← Jeffreys 先验，小样本自动向 0.5 收缩
retention     = exp(-ageDays / S)
S             = 2.5×(1+0.45×streak)×(1+0.25×ln(1+attempts))
prereqSupport = 0.35×mean(prereq) + 0.65×min(prereq) ← 无先修时返回 0.5
prereqCeiling = 0.55 + 0.45×min(prereq)              ← 无先修时返回 1.0
最终 clamp 到 [0,1]
```

**必须提供的成员**：

### 4.2 `Algorithms/DebtScanner.cs` — impact-v2

```
sigmoid(x) = 1/(1+exp(-x))
若 freq ≤ 0 → impact = 0（硬短路，必须）
impact = 0.55 × sigmoid((scoreFrom-0.55)×8) × sigmoid((0.50-scoreTo)×8)
              × max(weight,0) × cross × cascade × volume
cross   = 1.0（prerequisite）| 1.15（transfer_gap）
cascade = 1 + 0.12×ln(1+downstreamCount)
volume  = 1 + 0.08×ln(1+freq)
IsHit   ⇔ freq > 0 且 impact ≥ 0.08
```

必须成员：`CrossFactor` / `Readiness` / `Gap` / `Cascade` / `Volume` / `ComputeImpact` / `IsHit`。
另需保留 v1 兼容类 `DebtScannerCompat.ComputeImpactV1`（**金样在用**）：

```csharp
recency   = 1/(1 + daysSinceLastError/7)
detected  = scoreP < 40 && scoreC < 50 && freq > 0      // 0–100 分制
impact    = detected ? freq×(50-scoreC)×recency×weight : 0
```

### 4.3 `Algorithms/SaleStateMachine.cs` — sale-v2

```csharp
public enum SaleStatus { Open, Repairing, Cleared }
public sealed record SaleAttempt(bool Correct, double Accuracy, int SelfConf);
public sealed record SaleState(SaleStatus Status, int Streak, int Attempts, int WeightedScorePct = 0);

weighted = 0.7×clamp(acc,0,1) + 0.3×clamp(conf/5,0,1)
meets    = weighted >= 0.65 && acc >= 0.7 && conf >= 3
streak'  = meets ? streak+1 : 0
attempts'= attempts+1
cleared  ⇔ streak' >= 2 && attempts' >= 3
status   = cleared ? Cleared : (streak>0||attempts>0 ? Repairing : Open)
Cleared 为终态：已 Cleared 再 Transition 直接原样返回
```

另需 `SaleCompat.IsSaleable(history)`（金样口径，只看连续达标，不看累计次数）与 `CanWriteCleared(serviceId)`（仅 `progress-svc` 返回 true）。

### 4.4 `Planner/PlannerConstraintChecker.cs` — K1–K5

| 码 | 含义 | 判定 |
|---|---|---|
| **K1** | 单日超预算 | 当日所有非 dropped 项 `est_min` 之和 > `dayBudgetMin` |
| **K2** | 同知识点连续 3 天高难度 | 连续三天都出现同一 `kpId` 且 `difficulty ≥ 4` |
| **K3** | 理由缺失/不溯源 | `why` 为空，或 `why` 不含 `from_kp_name` |
| **K4** | 顺序错误 | 同一 `kpId` 内，`drill/quiz` 排在 `concept` 之前 |
| **K5** | 债边未覆盖 | topDebts 里的边既没被覆盖，也没有 `status="dropped"` 的原因 |

### 4.5 `Algorithms/PlannerBuilder.cs` — 14 天计划

```
按 impact 降序遍历债边，每条债边排 3 遍，间隔偏移 {0, 2, 6} 天：
  第 p 遍（p=0,1,2）：
    先修点放 day = 1+offset[p]，layer=core，分钟 = (p==0 ? 20 : 12)
    当前点放 day = 1+offset[p]+1，layer = (p==0 ? challenge : core)，分钟 = (p==0 ? 15 : 10)
约束：
  core 单条 ≤25 分钟，challenge 单条 ≤15 分钟
  同一 kp 两次之间至少隔 1 天
  单日累计 ≤ dayBudget（默认 40）
  放不下就往后找，找到 horizonDays 为止
```

### 4.6 `Algorithms/QuestionScheduler.cs` — 自适应选题

```
TargetDifficulty(score) = clamp01(score + 0.15)          ← 最近发展区
DifficultyFit(d, score) = exp(-4×(d - target)²)
Priority(q) = (1-score)^1.2 × (impact+0.05) × DifficultyFit × (1 + ageDays/14)
Pick(pool)  = Priority 最高的那条
```

### 4.8 `Ocr/` — OCR 文本清洗

`OcrTextEngine` 必须提供：`FixConfusions` / `FilterNoise` / `ReconstructCjkLines` / `ReconstructFromTsvWords` / `VotePasses` / `Score` / `Refine`。
要点：
- 全角标点归一（，。：；（）【】→ 半角）
- 字母词内 `0→O` `1→l` `5→S` `8→B`，但**形如 `C02`/`N1` 的技术词保留数字**（正则 `^[A-Z]\d+$` 跳过）
- 中英粘连处插空格
- 中文软断行合并：行尾无标点 + 下一行是汉字 → 合并
- 三遍 PSM 投票：同一行在 ≥2 遍出现才保留
- TSV 置信度加权，低于阈值的词丢弃

`ReadingOrder.Sort`：XY-cut，先横切后纵切，处理两栏排版。

### 4.10 `Agent/AgentRouter.cs`

- `PatternSet`：归一化（全角→半角、空白折叠、小写）+ `Contains` 级联 + 正则回退；提供 `ContainsAny` / `MatchFirst`。
- 意图表（15 种，锚点词表见 P1 提示词 4.3）：`debt.diagnose` / `debt.explain` / `plan.create` / `plan.rebalance` / `today.tasks` / `practice.start` / `progress.check` / `graph.view` / `material.parse` / `kb.search` / `profile.view` / `profile.optout` / `whatif.simulate` / `sale.check` / `meta.help`。
- 优先级：**危机词 → 最高**，`decision="crisis.handoff"`，`score=1`，直接返回 P1 给的安抚句。

## 10. 常见坑

| 坑 | 表现 | 解决 |
|---|---|---|
| 一次 `dotnet test` 接多个项目 | `MSB1008: 只能指定一个项目` | 逐个跑 |
| 金样目录找不到 | `DirectoryNotFoundException: eval/golden not found` | 把 `eval/` 复制到测试输出目录，或在 `GoldenDir` 候选里加本机绝对路径 |
| 用 v2 公式去对 v1 金样 | 数值永远对不上 | 金样走 `ScoreCalculator`（v1，0–100）；产品走 `MasteryCalculator`（v2，0–1） |
| `PrereqSupport` 空数组 | 除零 / NaN | 空数组返回 0.5，`PrereqCeiling` 返回 1.0 |
| TextRank 词表太大 | 构图卡死 | `maxConcepts` 限 24，PMI 阈值 1.0 |
| 正则依赖句式退化 | 抽不到边 | 概念表要先按 TextRank 截断，再跑正则 |
| NuGet 报 `path1=null` | 还原失败 | 补 `PROGRAMDATA` / `PROGRAMFILES(X86)` / `ALLUSERSPROFILE`，`CheckEolWorkloads=false` |
| 偷偷改了系数 | 金样红但"看起来更合理" | **禁止**。要改必须四人开会，并同步更新全部金样 |
