## 1. 知识图包 graph_pack.json（accounting-v1 等）

### 1.1 Schema
```json
{
  "packId": "accounting-v1",
  "course": "会计基础",
  "nodes": [
    {"kp_id":"N1","title":"会计要素","course":"会计基础","difficulty":1,"kind":"chapter","why":"教材第1章"}
  ],
  "edges": [
    {"from_kp":"N1","to_kp":"N2","edge_type":"prerequisite","weight":1.0,"why":"先有要素才能理解等式"}
  ]
}
```
`edge_type` ∈ {prerequisite, transfer_gap}。`from→to` = 先学 from 再学 to。

### 1.2 必须包含（会计）
N1 会计要素 → N2 会计等式 → N3 借贷记账法 → N4 会计分录 → N5 试算平衡 → N6 账户结构 → N7 财产清查 → N8 财务报表
transfer_gap 示例：N3 → N5（记账到试算的迁移缺口）

### 1.3 另两包（可并入同一文件分组或分开）
- `python-v1`：变量/类型/函数/列表/字典/类/异常/文件/模块/虚拟环境/测试/装饰器/生成器/并发/包管理…
- `dl-v1`：神经元/激活/损失/梯度下降/反向传播/卷积/池化/RNN/注意力/Transformer/正则化/过拟合/数据增强…

**总量**：30 节点、≥50 边、无环、每个节点至少一条边（或标注 root）。

### 1.4 校验规则（写进脚本）
1. `edges` 端点必须存在于 `nodes`
2. 拓扑无环（可用 Kahn）
3. 无重复边
4. difficulty ∈ 1..5
5. `why` 非空（可溯源）
