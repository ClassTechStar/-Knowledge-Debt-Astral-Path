知债：星穹学途

Knowledge Debt: Astral Path —— 跨课程知识债诊断与修复智能体。用固定公式找出你「欠」了哪门课的先修债，用可完成的 14 天计划一步步销账。

桌面端 ≡ Web 端 Windows 10 / 11 教学辅助 · 不构成处分依据 consent fail-closed

它解决什么问题？

多门课交叉学习时，卡住往往不是「这一章没听懂」，而是前面某门课的先修概念没打好——这就是「知识债」。

五分钟上手

1
启动应用

安装版双击桌面图标，状态栏出现「已就绪」。开发者：dotnet run --project src\AstralPath.Api -- --urls http://127.0.0.1:5190

2
藏书阁 · 导入教材

点「导入示例资料」，或「上传并解析」自己的 PDF。等状态变成绿色 ready。

3
识网 · 看图谱与章节

切换教材卡片 → 画布是完整目录思维导图 → 右侧章节侧栏点一章，看正文与本章自动出题。

4
知债 · 看红边与计划

BASELINE 诊断叙事 + 教材识网红边；拖 What-if 滑块理解 impact；「生成 14 天计划」每天 ≤35 分钟。

5
今日 · 做题

「加载教材真题」→ 答题并拉信心条 →「换一批题」轮换题库。

6
智能体 · 问一句

试试「帮我诊断知识债」「生成14天计划」。危机相关表述会自动转人工。

功能详解

六大模块：藏书阁 · 识网 · 知债 · 今日 · 智能体 · 画像（另有账户）。

1. 藏书阁

能力说明
上传 PDF多选；文本层优先全书抽取
扫描版 OCR可选 Tesseract（chi_sim+eng）；有文本层则不依赖 OCR
深度解析全文字符 · 完整目录 · 章节正文 · 按章自动出题
示例教材Kotlin / Python / Java / Go / C# / 深度学习系列 / AI Agent / 人物传记等

2. 识网（知识图谱）

能力说明
思维导图完整目录入图（章/节/小节），DAG 无环
章节侧栏点章看正文摘要 + 自动出题（含答案）
教材真题每书约 12 题，可轮换
导出Markdown 大纲 / RDF 三元组
布局分层图谱 / 逻辑结构图；节点拖拽、画布缩放平移

3. 知债诊断

能力说明
红边列表BASELINE impact + 可访问性表格 + 诊断叙事
教材债边识网 preview-debts（如 神经网络→反向传播）
14 天计划K1–K5 约束；任一天 ≤35 分钟
What-if实时模拟 score / freq / days → impact
教师热点consent fail-closed，未授权不进热点

4. 今日任务

教材真题优先 → 选项 + 信心滑条 → 提交。支持换一批、重置题序、Demo +1 天。教练节奏：概念卡 → 桥接题 → 小测。

5. 画像

能力说明
能力雷达掌握度 / 正确率 / 练习量 / 还债进度 / 信心
掌握度表知识点 score / acc / 色带
时间线按日聚合；无记录时用掌握度基线
Opt-out关闭个性化标签（不影响学业事实）
CSR 索引图谱紧凑邻接统计

核心公式（冻结 BASELINE）

score = 100 × (0.6×recent_acc + 0.3×sev_norm + 0.1×self_conf/5) sev_norm = 1 − min(sev, 1) impact = freq × (50 − score_c) × recency × weight recency = 1 / (1 + days/7) 触发：score_p < 40 ∧ score_c < 50 ∧ freq > 0 销账：cleared ⟺ 连续 2 次 quiz acc≥0.7 ∧ conf≥3 （仅 progress 路径可写 cleared）

常见问题

桌面空白 / 本地服务启动失败？

请安装端口修复版（不得在 appsettings 写死 urls）。日志：%LOCALAPPDATA%\AstralPath\api-stdout.log。

扫描版解析很少？

安装 Tesseract（chi_sim+eng），traineddata 放到 api\tools\tessdata\。有文本层的 PDF 不装 OCR 也可用。

教师看不到学生？

故意设计：consent fail-closed，需学生授权。

桌面和 Web 会不会不一致？

桌面为 WebView2 内嵌同一 index.html，功能、布局、交互、数据逻辑一致。
