## 一、对比结论（数据）

| 指标 | 结果 |
|------|------|
| 样本页可读字符 A | 48,871 |
| 样本页可读字符 B | 57,713（**+18.1%**） |
| 词级 Jaccard 均值 | 0.08–0.61（**不能当内容错误率**） |
| 同字数但顺序全异的页 | 黄仁勋 p58：1136 vs 1136，J=0 |
| 项目明显更多的书 | 强化学习 +3063、自制框架 +2982、Java +1948 |
| 独立略多的页 | 扫描书封面/彩页（大模型 p83 独有 34 字） |

**真实差异来源**（非识别错误）：
1. **排序**：项目 TBPU GapTree 重排阅读顺序；独立为 PDF 流式顺序 → 中文无空格时词 Jaccard 崩到 0
2. **块合并**：项目把行拼成段（`word_separator`），独立保留碎片 → token 形态不同
3. **图片块**：项目 mixed 对 `type==1` 图片 OCR；独立抽样只 OCR 文本层 <40 字的页
4. **渲染倍率**：项目 `MinSize=1080`，独立 1.25x → 扫描页清晰度不同
