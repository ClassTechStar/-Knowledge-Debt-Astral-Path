## 零、先花 3 分钟看懂全局

### 1. 这个项目到底是干什么的？

学生学三门课（会计 / Python / 深度学习），前面没学懂的地方会拖住后面。我们把这种"前面欠下的账"叫**知识债**。

产品只做四步，多一步都不做：

| 步骤 | 大白话 | 类比 |
|---|---|---|
| **诊断** | 找出"会计等式 → 借贷记账法"这类拖后腿的红边 | 体检找病灶 |
| **计划** | 排出 14 天补课表，每天不超过 40 分钟 | 开药方 |
| **练习** | 做真题，系统记住你对没对、有多自信 | 吃药复查 |
| **销账** | 连续两次达标、累计三次，这条债就算还清 | 痊愈出院 |

### 2. 三个数字决定一切（记住这三个，就够了）

| 数字 | 名字 | 干什么用 | 谁负责算 |
|---|---|---|---|
| **score** | 掌握度 0~1 | 这个知识点你掌握得怎么样 | P2 写公式 / P3 验算 |
| **impact** | 影响分 | 这条"债"有多致命，越高越红 | P2 写公式 / P3 验算 |
| **cleared** | 销账状态 | 这条债还清没有 | P2 写状态机，**只有它能改** |

### 3. 四个人各自管什么（一句话版）

| 人 | 外号 | 一句话 | 手上主要产出 |
|---|---|---|---|
| **P1** | 产品/伦理 | 定口径、守底线、讲好故事 | 文案表、禁词表、隐私口径、演示稿 |
| **P2** | 算法/后端 | 算得准、跑得稳、接口清 | 公式库 Core、API 服务端、金样测试 |
| **P3** | 数据/评测 | 数据可信、测得住 | 知识图包、题库、金样、验收脚本 |
| **P4** | 客户端/体验 | 看得懂、演示稳 | 一份 index.html、安卓壳、Windows 安装包 |

### 4. 谁也不许踩的红线（四个人都背下来）

1. **数字只能算出来**：任何分数、排名、掌握度，不许 AI 编，不许手写死值。
2. **AI 不许改数字**：大模型只能润色语气，一个数字都不能动。
3. **不许发明先修边**：图里的"谁是谁的先修"必须来自教材/图包，不能靠 AI 想象。
4. **`cleared`（已销账）只有一个地方能写**：P2 的销账状态机，其他任何人/任何模块不许写。
5. **不许出现羞辱、恐吓、处分类的话**："笨""废物""退学""处分"全部禁止（完整表见 P1 交付物）。
6. **项目名只叫「知债：星穹学途」**：禁止"知债图""ZhiZhaiTu""zhizhaitu""zz_"这些旧名，代码里也不行。
7. **技术栈不许换**：C# / .NET 10 / Avalonia / SQLite / 一份 index.html 已锁定，别提议 Flutter、React、Java 后端。

## 附录 A · 三个公式（P2 拥有，P3 验算，全员看得懂）

> 你不需要会算，只要知道"这三个数字是怎么来的"就够了。

```text
【score 掌握度 · 0~1】
score = min( 0.50×know + 0.30×retention + 0.20×prereqSupport ,
             0.55 + 0.45×min(先修们) )
know       = 0.85×(做对数+0.5)/(作答数+1) + 0.15×(平均信心/5)
retention  = exp(-距今天数 / S)
S          = 2.5×(1+0.45×连对数)×(1+0.25×ln(1+作答数))
先修支撑   = 0.35×均值 + 0.65×最小值      ← 最弱的那一项最拖后腿

【impact 影响分 · 越高越红】
impact = 0.55 × σ((先修分-0.55)×8) × σ((0.50-当前分)×8)
              × 边权 × 跨章系数(1.0 或 1.15)
              × (1+0.12×ln(1+下游节点数))
              × (1+0.08×ln(1+错误次数))
命中红边 ⇔ 错误次数>0 且 impact ≥ 0.08

【sale 销账】
加权分 = 0.7×正确率 + 0.3×(信心/5)
达标   ⇔ 加权分≥0.65 且 正确率≥0.7 且 信心≥3
还清   ⇔ 近期连续 2 次达标 且 累计作答 ≥3 次
状态   : 待修复(open) → 修复中(repairing) → 已销账(cleared，终态)
```

**人话版**：
- 掌握度看三件事：做对过没有、还记不记得住、前面的基础牢不牢。
- 影响分看三件事：前面是不是该会、后面是不是真不会、堵住了多少后面的知识点。
- 销账防作弊：不能两题就清账，必须连续两次达标、累计三次。
