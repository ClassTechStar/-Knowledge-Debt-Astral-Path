正是方案 P3 预判的「第四副本漏同步」。

3. `.cloudflare/sync.sh` 改为从 `shared/integrations/` 复制，部署目录禁止手工编辑。

**门禁**：`scripts/verify_agent_intents.py` 由四方扩到**六方**对拍
（json / 主 HTML / C# 登记表 / C# 运行时词表 / p2 / shared-core），输出：
`ALL GREEN · agent-intents 多方一致（json=26 js=26 cs=26 p2=26 core=26 意图…）`

- `verify_all.ps1` 新增 `-Json` 机器可读摘要 + 4 个 Step（check-js / xss-cases / shared-core-generated / shared-core-equivalence）

### P2 共享内核单源化

- `scripts/verify_core.py`：**双跑对拍**——把 index.html / p0 / p1 / p2 的旧实现抽出来与 core.js
  在同一组用例上同跑，6 份实现 × 20 用例**全部等价**（落实方案 P2 的「新旧双实现并行断言」灰度策略）

### P4 XSS 收口

- `shared/safe-dom.js`（UMD）：`esc` / `safeRich`（白名单 `b/i/code/br/strong/em`，**带属性的标签整体拒绝**）/
  `setText` / `setHTML` / `sanitizeUrl`（拦截 `javascript:`）
- `contracts/golden/xss-cases.json` 14 例（img onerror / script / svg onload / iframe / 带属性白名单标签 /
  body onload / input autofocus / mutation XSS / 属性闭合逃逸 / `javascript:` + 3 例不误伤富文本）
- `scripts/verify_xss.py`：黄金用例 + 源码直插点哨兵

**审计结论（86 处 innerHTML 逐一判定）**：

| 类别 | 处置 |
|---|---|
| GLOSSARY / HELP_GUIDE / TEACHER_GUIDE 渲染 | 静态字面量，**无需改** |
| 数值/日期拼接（score、acc、gs、total） | 非字符串注入面，**无需改** |
| 教材名/知识点名/AI 流式 onDelta 回写 | 已 `esc()`，**无需改** |
| `renderTrend` 的 SVG 文本节点 `d.label`、学情报告 `rowsTrend` 首列 | **已修**：改 `esc(d.label)` |

**两条踩坑记录**（写进用例 _meta 与脚本注释，供后续维护）：
1. 断言要按「**转义型**」语义写——`safeRich` 转义后文本里仍含 `onerror` 字面量但已失活；
   初版按剥离型消毒器写 `must_not_contain` 导致 9 例假红，改为只断言标记形态（`<img`、`<script`、未转义引号）。
2. 直插点哨兵需三重收敛（**局部 25 行窗口** + 必须拼接标记字面量 + 承载模型/用户内容的属性），
   否则跨作用域跟随 `i`/`b`/`n`/`data` 等通用变量名会产生 74 处假红。
