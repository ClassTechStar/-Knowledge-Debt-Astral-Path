2. 核心算法（必须逐字实现）

2.1 掌握度 score-v2

score = min( 0.50·know + 0.30·retention + 0.20·prereqSupport , 0.55+0.45·min(prereq) )
know   = 0.85·Beta(成功,失败; Jeffreys) + 0.15·(meanConf/5)
Beta   = (s+0.5) / (attempts + 1)
retention = exp(-age_days / S)
S = 2.5 · (1 + 0.45·streak) · (1 + 0.25·ln(1+attempts))
prereqSupport = 0.35·mean(prereq) + 0.65·min(prereq)   // 最弱链
// 域恒为 [0,1]

2.2 影响分 impact-v2

impact = 0.55 · readiness · gap · weight · cross · cascade · volume
readiness = σ((score[from] - 0.55) · 8)     // σ = 1/(1+e^-x)
gap       = σ((0.50 - score[to]) · 8)
cross     = 1.0 | 1.15 (transfer_gap)
cascade   = 1 + 0.12·ln(1 + 下游节点数)
volume    = 1 + 0.08·ln(1 + freq)
// 命中：freq>0 且 impact ≥ 0.08（无悬崖门限）

2.3 销账 sale-v2

Weighted = 0.7·acc + 0.3·(conf/5) ≥ 0.65
         ∧ acc ≥ 0.7 ∧ conf ≥ 3
cleared  ⇔ 近期连续 2 次达标 ∧ 累计作答 ≥ 3 次
         且 status ∈ {open, repairing}
// 只能由 SaleStateMachine.Transition 写 cleared（终态）

2.4 计划 K1–K5 + PlannerBuilder

码约束
K1每日总时长 ≤ 预算（默认 40）
K2先修任务日 ≤ 依赖任务日
K3core ≤ 25 分 / challenge ≤ 15 分
K4同一 KP 两次任务间隔 ≥ 1 天
K5所有 open 债边被覆盖或显式跳过
PlannerBuilder：impact 降序 → From 先于 To（拓扑）
间隔重复 day = 1 + {0, 2, 6} 三遍
在 preferDay 附近找合法日塞入，自动满足 K1/K3/K4

2.5 选题 QuestionScheduler

Priority = (1-score)^1.2 × (impact+0.05) × exp(-4·(d - (score+0.15))²) × (1+age/14)
// 目标难度 = 能力 + 0.15（最近发展区）

2.6 知识图谱

// 构图 GraphInference.BuildFromText
TextRank 窗口加权共现 → 概念重要性（替代词频）
PMI 边权 = max(0, log2(co·N / a·b))，≥1.0 才连边
依赖句式「先学X再Y / 基于X…才能…」→ prerequisite
章节 backbone 弱边 + 概念挂靠

// 拓扑 GraphTopology
Layers(n) = 1+max(Layer(prereq))          // 难度代理
CriticalPath                              // 最长硬骨头链
Bottlenecks：删点后「全图源点」不可达数   // 真割点
DownstreamMass：下游传递闭包规模          // 喺 impact.cascade

// 度量 / 布局 / 路径
PageRank(d=0.85) · Hub=√(in·out)+0.25(in+out)
GraphLayout：x=拓扑层，同层重心排序减交叉（Sugiyama 简化）
LearningPath：2.5×瓶颈 + 1.5×关键路径 + 层 + PageRank

2.7 OCR v2

预处理：灰度 → autocontrast(2%) → UnsharpMask
识别：PSM 3/4/6 三配置 + TSV conf≥45 词
重建：(Y 行带 8px, X) 阅读顺序；XY-cut 两栏
投票：行级多数票（≥⌈n/2⌉）
后处理：全角/数学号归一、中英粘连拆开、中文软断行合并、页眉过滤
质量分：CJK 占比 × 噪声率 × 置信度 → A/B/C/D

2.8 画像 UserProfiler

Brier = mean((conf/5 − 1{对})²)          // 信心校准
CalibBias = E[conf/5] − E[对]            // >0 过度自信
StyleVector = (AccuracyFirst, Calibrated, Steady, Independent, DeepDive)
Topics.Weight = (1−mastery) × (0.4+0.6·interest) × 难度适中
Smooth：EMA α=0.25
TeacherView：禁列域 {sensitive,crisis,semantic} + k-匿名（<3 抑制）
SoftNudge：软提示，禁止处分性文案
