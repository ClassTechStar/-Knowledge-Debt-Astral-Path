# 知债：星穹学途 · 新手使用指南与功能介绍

**Knowledge Debt: Astral Path** · 版本 1.3.0 · 适用 Windows 10/11

本指南面向第一次接触本产品的同学与老师：先知道它解决什么问题，再按步骤上手，最后了解每个功能模块能做什么。

---

## 一、产品是什么？

在多门课交叉学习时，你常常不是「这章没听懂」，而是**前面某门课的先修概念没打好**——这就是「知识债」。

**知债：星穹学途** 会：

1. **藏书阁**：把你的教材 PDF（或讲义）解析成文字与目录  
2. **识网**：自动画出全书知识图谱（思维导图），可点开每一章看正文与自动出题  
3. **知债**：用固定公式找出「先修没掌握 → 后面学不动」的红边，并生成 14 天还债计划  
4. **今日**：每天约 35 分钟的教材真题与练习  
5. **智能体**：随时问「我的知识债」「生成计划」；说危机相关的话会自动转人工  
6. **画像**：雷达图、掌握度、学习时间线  

> 合规声明：本系统**仅用于教学辅助与学习规划，不构成处分依据**。教师可见学生情况需学生授权（consent fail-closed）；敏感词会脱敏；危机内容自动转交人工支持。

## 三、五分钟上手（推荐路径）

### 步骤 1 · 启动

- **安装版**：双击桌面「知债：星穹学途」。状态栏显示「已就绪」即成功。  
- **源码版**（开发者）：

```powershell
cd C:\Users\18948\Documents\GitHub\-Knowledge-Debt-Astral-Path
dotnet run --project src\AstralPath.Api -- --urls http://127.0.0.1:5190
# 浏览器打开 http://127.0.0.1:5190/
```

### 步骤 2 · 导入教材

1. 点顶部 **「藏书阁」**  
2. 点 **「导入示例资料」**（约 11～12 本示例教材），或 **「上传并解析」** 选择自己的 PDF  
3. 等列表出现绿色 `ready`（大书可能要几十秒）

### 步骤 3 · 看知识图谱（识网）

1. 点 **「识网」**  
2. 上方教材卡片可切换书目  
3. 画布是**完整目录**思维导图（章 → 节 → 知识点）  
4. **右侧章节侧栏**：点任意章 → 看正文摘要 + **本章自动出题**（含选项与答案）

### 步骤 4 · 看知识债（知债）

1. 点 **「知债」**  
2. 上半：会计课程包 BASELINE 红边 + 诊断叙事  
3. 中部：**教材识网红边**（从你解析的书里挑出的债边）  
4. 右侧 **What-if**：拖滑块看 impact 公式怎么变  
5. 点 **「生成/刷新 14 天计划」**：每天 ≤35 分钟

### 步骤 5 · 做今日任务

1. 点 **「今日」**  
2. **「加载教材真题」** 出题；**「换一批题」** 轮换到题库下一组  
3. 选选项、拉「信心」滑条 → 提交（会计图内的知识点会更新掌握度）

### 步骤 6 · 问智能体

1. 点 **「智能体」**  
2. 试试：

| 你输入 | 系统行为 |
|--------|----------|
| 帮我诊断知识债 | 定位诊断意图并给出还债建议 |
| 生成14天计划 | 生成修复计划 |
| 我这周学不完 | 压力求助话术 |
| （危机相关表述） | **自动转人工**，不继续闲聊 |

## 四、功能模块详解

### 1. 藏书阁 · 资料库

| 能力 | 说明 |
|------|------|
| 上传 PDF | 支持多选；文本层优先抽取全文 |
| 扫描版 OCR | 需本机安装 Tesseract（可选）；中英 `chi_sim+eng` |
| 深度解析 | 全文字符、完整目录、章节正文、按章出题 |
| 示例教材 | 一键导入 Kotlin / Python / Java / Go / C# / 深度学习系列 / AI Agent / 人物传记等 |

**解析状态**：`parsing` 处理中 → `ready` 可用 / `failed` 失败。

### 2. 识网 · 知识图谱

| 能力 | 说明 |
|------|------|
| 思维导图 | 目录入图：章 / 节 / 小节，DAG 无环 |
| 章节侧栏 | 完整目录列表；点击查看正文与自动出题 |
| 按章出题 | 每章 2～4 题（概念 / 术语 / 方法），可作练习 |
| 教材真题 | 题库轮换（每书 12 题） |
| 大纲 / 三元组 | 导出 markdown 大纲、RDF 三元组 |
| 图布局 | 分层图谱 / 逻辑结构图；节点可拖拽、画布可平移缩放 |

### 3. 知债 · 诊断与计划

**掌握度（score）**

```text
score = 100 × (0.6×近次正确率 + 0.3×严重度 + 0.1×自信心/5)
```

**债边影响（impact）**

```text
impact = 出错频次 × (50 − 后置点得分) × 新近度 × 边权
触发：前置 < 40 且 后置 < 50 且 频次 > 0
```

| 能力 | 说明 |
|------|------|
| 红边列表 | 可访问性表格，附诊断叙事 |
| 教材 preview-debts | 从识网图谱预览教材债边 |
| 14 天计划 | K1–K5 约束检查；任一天 ≤35 分钟 |
| What-if | 实时模拟 score / freq / days 对 impact 的影响 |
| 教师热点 | 需学生 consent；未授权不进热点（fail-closed） |

### 4. 今日 · 练习胶囊

- 优先教材真题（有标准选项与正确项）  
- **换一批** 轮换题库；**重置题序** 回到开头  
- 教练提示：先概念卡 → 桥接题 → 小测  
- Demo +1 天：演示推进

### 5. 智能体 · 受约束助手

| 机制 | 说明 |
|------|------|
| 意图路由 | 诊断债 / 生成计划 / 叙事解释 / 工具调用等 |
| 危机转人工 | 命中危机词立即 handoff |
| 敏感词脱敏 | 禁词过滤，安全输出 |
| 工具白名单 | 按角色（student/teacher/demo）展示可用工具 |
| 会话状态 | sessionId 记录阶段（响应 / 澄清 / 人工） |

### 6. 画像 · 学习画像

| 能力 | 说明 |
|------|------|
| 能力雷达 | 掌握度 / 正确率 / 练习量 / 还债进度 / 信心 |
| 掌握度表 | 各知识点 score / acc / 色带 |
| 时间线 | 按日聚合练习；无记录时用掌握度基线 |
| Opt-out | 关闭个性化标签展示（不影响学业事实） |
| CSR 索引 | 知识图谱紧凑邻接统计（课程包 + 教材图） |

### 7. 账户

- 邮箱 + 密码注册登录（演示账户见上）  
- 绑定演示学生、改昵称  
- 登录后可拉取「教材今日任务」

## 六、常见问题

**Q：桌面窗口空白 / 提示本地服务启动失败？**  
A：请使用已修复端口问题的安装包（`appsettings.json` 不得写死 `urls`）。安装后仍失败时，看 `%LOCALAPPDATA%\AstralPath\api-stdout.log`。

**Q：扫描版 PDF 解析很少？**  
A：安装 [Tesseract](https://github.com/UB-Mannheim/tesseract)，语言包 `chi_sim` + `eng`，可将 `traineddata` 放到 `api\tools\tessdata\`。有文本层的 PDF 不需要 OCR 也能完整解析。

**Q：教师看不到学生？**  
A：这是**故意的**：consent fail-closed。需学生在账户或教师页「授权」。

**Q：销账（cleared）条件？**  
A：连续 2 次小测 正确率 ≥0.7 且信心 ≥3，且仅 progress 路径可写入。

**Q：界面和 Web 不一致？**  
A：桌面为 WebView2 内嵌同一 `index.html`；请确认安装包为 1.3.0-Desktop 修复版。
