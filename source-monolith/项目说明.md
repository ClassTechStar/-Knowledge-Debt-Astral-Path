# 知债：星穹学途——项目说明（单体版 2.6.0）

## 一、这东西是干嘛的

做这个项目，起因其实很简单：我们自己就是经常自学的学生，手头上攒了一大堆扫描版 PDF 教材，复制不了文字、章节结构乱七八糟，复习的时候根本抓不住重点。市面上的学习 App 要么只支持固定题库，要么就是要你手动把教材内容敲进去，对“长尾教材”几乎没辙。

所以我们想，能不能直接让浏览器把扫描教材“读”进去，自动画出知识骨架，再告诉你哪里缺了先修概念、该先补哪一块？这个想法后来就变成了“知识债”模型——把没掌握且拖累后续学习的概念当成一笔“债”，按影响大小排序，生成 14 天的间隔修复计划。

整个应用是一个单 HTML 文件，双击就能跑，不需要服务器、不需要注册账号，所有计算都在浏览器本机完成。

## 二、谁会用它，以及解决了什么麻烦

我们把目标用户分成三类，每一类的核心场景都对应了具体功能：

| 用户群体 | 核心场景 | 对应功能 |
|---|---|---|
| 自学型大学生 | 扫描教材复习、期末冲刺、考研备考 | 教材解析、知识图谱、薄弱诊断、每日任务 |
| 职业考证人群 | 知识点零散、手头的题库和教材对不上 | 语义出题、错题本按频次聚合、先修回溯 |
| 伴学教师/助教 | 想知道学生共性薄弱点在哪 | 掌握度画像、薄弱热点、授权可见的只读学情视图 |

对大学生来说，最头疼的是扫描版 PDF 没法结构化。我们的 OCR 引擎能离线识别整本教材，300 页的书大约 10–15 分钟，识别完直接生成可点击的知识图谱，复习时一眼就能看到“如果会计学不好，后面的财务报表也看不懂”这类先修关系。

考证人群通常知识点特别碎，我们的系统会根据教材内容自动出题，题目选项直接从原文出发，不会凭空捏造。错题本也不是简单罗列，而是按知识点频次聚合，反复错的题会优先弹出。

教师端我们做得比较克制：学生必须在本机点“同意授权”之后，老师才能看到该生的薄弱热点、红边清单和近 7 日作答趋势。没授权就彻底看不见，视图里还内置了示例班级面板（12 人聚合数据），按 k-匿名下限 3 人规则展示热点分布，方便课堂讲解。

## 三、开发平台：DuMate

项目的编排层是搭在 DuMate 平台上的。DuMate 提供了一个可视化无代码编排环境，我们把教育相关的算法能力（OCR、构图、出题、诊断、计划）封装成技能包，然后在编排层里用拖拽节点的方式把用户的话术路由到对应工具。

具体来说，DuMate 负责三件事：意图识别（判断用户想干嘛）、条件分支（比如有 API Key 就走大模型，没 Key 就走本地规则）、节点调度（把请求分发给正确的算法模块）。而真正的计算——OCR 识别、图谱构建、诊断公式、计划生成——全部在浏览器里跑，DuMate 本身不碰用户数据。

这种分工的好处是：编排层零代码，流程可以随教学场景快速调整；算法层保持稳定，不需要因为前端改个按钮就重写识别逻辑。对我们这种小团队来说，这种“前端重、后端轻”的架构省了不少维护成本。

## 四、技术方案：怎么拼出来的

整个应用是纯前端架构，核心是一个约 17 MB 的单 HTML 文件，里面内联了完整的 OCR 引擎、图谱算法和诊断公式。下面按模块简单说一下技术选型：

**OCR 与文档解析**

我们用的是 Tesseract WASM + pdf.js 的组合。解析流水线遵循“文本层优先”原则：先尝试提取 PDF 自带的文本层，如果可读字符太少或者乱码密集，就判定为扫描版，自动转入 Tesseract 图像识别阶梯。为了适配只能托管单个 HTML 文件的平台，我们把 Tesseract 的工作线程、神经网络计算核心和语言模型全部内联进了页面，运行时零外部请求。图像直拍识别（照片、截图、画布图像）走的是同一套识别参数，试卷、作业、错题拍照导入的识别质量与扫描页一致。

除了 PDF，我们还支持 PPT、Word、EPUB、HTML、Markdown、TXT 和图片导入。新版 Office 格式和 EPUB 本质上是 ZIP 容器，我们用纯脚本解析目录和解压；旧版二进制 Office 文档则按文本游程尽力提取，正文过短时会自动调用识别引擎补偿内嵌图片。

**知识图谱自动构建**

图谱由章节节点、术语节点和三类边（先修、共现、锚定）组成。构建分三步：章节识别通过页式目录、行级标记和句子聚合提取结构；概念抽取采用 TextRank 对句子构建共现图并迭代排序，同时用章节位置加权和领域词典过滤碎片词；共现关系用点互信息（PMI）度量，低于阈值的边直接丢弃。最后用 Kahn 拓扑排序去掉先修关系里的环路，保证债网可以正常传播。

**学习诊断算法**

掌握度公式综合了三类信号：经验正确率（权重 0.5）、遗忘衰减（权重 0.3）和先修支撑（权重 0.2）。影响分则用来衡量一条先修边的修复价值，考虑了掌握度差的 sigmoid 衰减、边权、跨章系数和作答频次因子。销账判定要求连续两次达标且累计作答不少于三次。

修复计划按影响分降序选取债边，以 0、2、6 天的偏移安排三遍复习，单日预算默认不超过 40 分钟。计划生成后还要过 K1–K5 五项可校验约束：单日时长预算、先修有序、任务说明必须包含先修知识点名称、同一知识点间隔不少于一天、开放债边至少被覆盖或被显式延期。如果计划不合规，合约引擎会自动修复（时长压缩、任务顺延、说明回填与先修顺序调整），修复后仍不合规则回退为本地规则生成的计划。

**受约束智能体与 ONNX 前端模型**

智能体采用三级意图路由：规则表以关键词锚点精确命中；轻量 ONNX 神经网络模型补强口语化表达；模糊锚点以子序列覆盖率做二次确认。危机类意图具有最高优先级，命中后立即输出心理援助转介话术且不可覆盖。输出侧有敏感词拦截，身份证号、银行卡密码等内容一律以提示语替代。

这里比较特别的是我们塞了一个小型 ONNX 模型进前端，纯网页跑意图分类。模型不大，但足够处理“帮我生成计划”“查一下知识库”这类口语化指令。没有网络或者没有配置 API Key 的时候，本地模型+规则引擎就能完成大部分路由任务。

**大语言模型的受控集成**

大模型（我们接的是小米 MiMo，也兼容其他 OpenAI 格式接口）深度参与了三个业务模块：图谱增强构图（依据章节目录和已有术语抽取概念与先修关系）、识别文本清洗（分块纠错，仅修正形近字和断行，用块级长度比和整体可读字数双重保护抑制幻觉）、个性化建议与智能出题。

但我们给大模型设了硬边界：所有评估数字（掌握度、影响分、销账状态）只由本地公式计算，大模型只能复述工具结果，不能改写数字。大模型负责的是语言层任务——把枯燥的数字翻译成“你的会计等式薄弱点正在拖累后面的财务报表”这类学生能听懂的话。教材之外的内容以【拓展】标注，与教材冲突时以教材为准。

**无密钥演示模式**

考虑到评审和新用户通常没配 API Key，我们做了演示模式：各处智能入口在未配置状态下由本地规则引擎按同一链路生成结果，界面明确标注“演示模式”。配置密钥后自动切换为大模型输出，不伪造、不误导。

## 五、具体能干什么（AI 在里面扮演了啥角色）

应用有 8 个主要页面，每个页面的 AI 参与方式都不太一样：

**起点**：首次进入会弹出启动加载屏，告诉用户正在装载约 17 MB 的离线引擎，首次稍慢但完成后完全离线可用。页面上有导入示例教材的按钮，点一下就能体验完整流程。

**藏书阁**：上传教材的地方。支持多文件批量导入，解析模式分 quick（章标题+抽样）、standard（目录+正文构图）和 none（仅文本层）。扫描版教材会自动提示“约 1–3 秒/页，300 页约 10–15 分钟”。AI 在这里负责扫描版识别、文本清洗和多格式解析。如果 OCR 也不可用，还可以直接粘贴文本兜底。

**识网**：教材解析完成后自动生成知识图谱。蓝色节点是章节，绿色是术语，红色是知识债。点击节点能看到摘要和先修关系。这里有两个 AI 功能：一是“AI 增强构图”，大模型会根据章节目录补充概念和先修关系；二是图谱导出，支持三元组、属性图、思维导图和 Markdown 大纲四种格式。节点数超过 200 时自动切换 Canvas 渲染，保证流畅。

**试卷·作业·错题**：这是 T10 版本新增的模块。拍照、截图、图片粘贴、文件导入四类入口，识别结果经确定性规则结构化：先识别板块与题型分区，再切分题头、选项与答案，题型按题干特征推断为选择、填空、判断与解答四类。AI 在这里负责图像识别和初步结构化，但题型推断和知识点匹配是本地确定性规则完成的。结构化结果会生成三层知识点图谱（主题→知识点→题目），边分归属、考查、同题共现和先修四类。

**知债**：核心诊断页。点“重新诊断”会扫描所有开放债边，按影响分排序，红色显示。点“生成 14 天计划”会调用 AI 计划官：模型读取教材目录、债边相关章节正文、学习者画像摘要和当日快照，输出结构化计划草案。但草案不直接落库，必须先过 K1–K5 合约校验，知识点名称必须通过本地白名单。每条红色债边还会生成“现状—拖累对象—建议动作”的债务解读，帮助学生理解为什么先补这一块。

**今日**：每日任务页。加载后展示当天的修复任务和练习题。练习优先展示题池中的模型命题（上下文约 3600 字，包含知识点正文、章节全文和全书目录），题池空了才实时生成并标注“生成中”。作答时可以选择信心 1–5，系统据此调整掌握度计算。页面上还有 AI 学习建议卡，基于当日快照生成 2–3 条可执行建议，按自然日缓存。

**智能体**：对话助手。输入框支持自然语言，比如“我这周学不完计划了”“帮我诊断知识债”。路由轨迹会实时显示在对话下方，方便用户理解系统是怎么理解自己的话的。快捷按钮包括压力求助、诊断债、生成计划、识网摘要、销账检查、今日任务。侧边栏可以配置 API Key（AES-GCM 加密存储），配置后“云端优先”的讲解类意图会先问大模型。

**画像**：掌握度列表、错题本（按频次聚合）、学习风格五轴（Brier 准确度、Steady 稳定性、Independent 独立性等）。可以随时 opt-out 关闭个性化画像，数据存在本机，不上传。

**教师视图**：学生授权后才展示数据。包含学情概览、薄弱热点 TOP、红边清单、近 7 日作答趋势。示例班级面板用于课堂演示。教师可以按薄弱热点生成作业单文件（JSON），学生在“今日”页导入后排入当日任务；学生也可以导出自己的学情报告（HTML，可打印为 PDF）回传给老师。

**账户**：教师可见授权（同意/撤销）、演示身份设置、学情报告导出、数据导出/重置、液态玻璃外观切换。密钥经 AES-GCM 加密后落盘，localStorage 只存密文，解密密钥存在 IndexedDB 中不可导出。

## 六、怎么上手用

**第一次打开**

双击 HTML 文件（或者用 serve.ps1 启动本地服务器），会看到启动屏提示正在加载离线引擎。加载完成后进入“起点”页，建议先点“导入示例教材”体验一遍完整流程。右上角有个“？”按钮，点开会看到三步上手说明（导入资料→查看识网→开始任务）和术语词典，覆盖知识债、红边、先修、影响分、销账等核心概念。

**导入教材**

去“藏书阁”页，点文件选择框选 PDF/PPT/Word/图片等，选解析模式后上传。扫描版会自动走 OCR，普通 PDF 直接提取文本层。解析完成后在“识网”页能看到生成的知识图谱。

**查看知识债**

去“知债”页，点“重新诊断”。如果还没有红边（说明示例数据没载入），可以点“去练三道题解锁”或者“载入演示诊断”来体验红边生成过程。有红边后点“生成 14 天计划”，可以在输入框里补充要求，比如“每天不超过 30 分钟”“先重点补会计等式”。计划生成后能看到每日任务列表，也可以点“计划复盘”查看计划执行分析。

**每日学习**

去“今日”页，点“加载今日任务”，完成当天的修复任务和练习题。做题时如实选择信心等级，系统会根据正确率和信心调整掌握度。如果老师发了作业单文件，点“导入作业单”即可排入当日任务。

**问智能体**

去“智能体”页，直接输入问题，或者点下方的快捷按钮。如果想用大模型深度回答，先在侧边栏配好 API Key，勾选“云端优先”。

**拍照识别试卷/错题**

去“试卷·作业·错题”页，选类型（试卷/作业/错题），然后点拍照、截图粘贴或文件导入。识别完成后能看到结构化结果和自动生成的知识点层级图谱。

## 七、往后能走多远，以及怎么可持续

**商业模式**

我们设计了四层变现路径：第一层是免费个人学习版，也就是现在这个单文件应用，零成本获客；第二层是把教育算法能力封装成 DuMate 平台的编排技能，按调用量拿分成；第三层是面向高校和培训机构的校园授权，提供批量解析和学情看板，按席位收年费；第四层是与出版社共建正版结构化教材包，从源头解决版权问题。个人版采用用户自带密钥模式，我们不垫付模型成本，免费层可以一直跑下去。

**应用前景**

近期主要服务高校期末冲刺和考研自学场景，这两类用户对扫描版教材的结构化需求最强。中期可以扩展到职业资格考试领域，比如 CPA、法考、建造师等，这些考试的知识体系高度结构化，与知识债模型天然契合，机构学情看板也能构成商业切入点。远期我们希望与出版机构合作，把正版教材做成结构化知识包，编排技能也可以被其他教育类应用复用，从工具走向平台资产。

**合规边界**

应用内所有上传区都固定展示“仅限个人学习使用”提示，要求用户只上传合法拥有的资料副本，解析产物不得公开分发或商用。全部学习数据存于本机浏览器存储空间，没有账号体系，也不上传服务器。模型密钥经 AES 加密后本地落盘，平台侧不可见。

**局限与下一步**

目前的主要短板有三个：一是长尾学科的领域词典覆盖还不够全，一些冷门专业的术语抽取准确率会下降；二是识别引擎对数学公式和代码块的准确率有限，复杂排版时识别结果需要人工复核；三是模型增强效果依赖用户网络与密钥配置，离线场景下只能走本地规则兜底。后续我们会围绕学科词典扩展、版面分析增强和端侧小型模型引入三个方向继续迭代。
