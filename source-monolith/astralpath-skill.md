## Design and Implementation of an Intelligent Self-Study Tutoring Application Based on the Knowledge-Debt Model

</div>

**Abstract:** To address the common pain points in self-study scenarios, namely that scanned textbooks are hard to structure, revision lacks focus, and wrong answers go unanalyzed, this project designs and implements an intelligent self-study tutoring application named "Knowledge Debt: Astral Path". Centered on a knowledge-debt model, the application parses textbooks into a knowledge graph consisting of chapters, terms and prerequisite relations, locates the learner's weak prerequisite chains through an impact-scoring algorithm, and generates a fourteen-day spaced repair plan, forming a complete learning loop of parsing, diagnosis, planning, practice and debt clearing. The application also covers practice scenarios: exam papers, homework and wrong answers can be recognized directly from photos, screenshots or imported images, and the results are automatically structured into a knowledge-point graph that makes hierarchical attribution and associations explicit; document import is extended to PPT, Word, HTML, Markdown, TXT and EPUB, and parsed content enters the same structuring and graph-building pipeline. The main work includes: building an OCR engine ladder with Tesseract and pdf.js and inlining the full engine stack so that a single HTML file can complete offline recognition and structuring of scanned textbooks in a pure browser environment; realizing automatic knowledge-graph construction based on weighted TextRank and point-wise mutual information co-occurrence; designing three explainable algorithms covering mastery, impact and debt clearing to support learning diagnosis; introducing large language models for deep participation in graph augmentation, recognized-text polishing, personalized suggestions, intelligent question generation and repair-plan orchestration, with every generated plan required to pass five verifiable constraints, together with a key-free demonstration mode that requires zero configuration; and observing the compliance boundary of personal learning use only. Test results show that the application achieves a success rate of one hundred percent on twenty-seven real textbooks, improves scanned-page recognition speed by more than forty-six percent over the serial baseline, and keeps all diagnostic figures computed by local formulas, hence explainable and auditable; all repair plans pass the five-constraint verification in dedicated tests. Fifty-five end-to-end smoke assertions covering exam recognition and multi-format import all pass, with Chinese recognition confidence of ninety on sample images. In addition, a systematic usability pass was carried out from an ordinary-user perspective: a read-only teacher view gated by student consent (weak-point hotspots, a red-edge list, a seven-day activity trend and a sample-class demo), one-click export of a student-learning report and a homework-sheet file hand-off, together with student-side onboarding guidance, a glossary, locally persisted chat history, simplified graph rendering and a first-load screen; all improvements pass twenty-four end-to-end assertions. On top of that, the availability and responsiveness of the AI functions are secured: cloud requests pass a concurrency gate with FIFO queuing so they never block each other, the reasoning trace of the inference model is streamed to the interface in real time, question generation first shows a fallback item when the pool is empty and replaces it with the AI-generated one once ready, failed requests are retried automatically, and the failure cooldown lasts only eight seconds. Measurements show the first practice item appears within 0.2 s, an AI-generated item replaces it in about 19 s, and thinking feedback becomes visible within 2.6 s, with no runtime errors in the whole flow, all confirmed end-to-end against the live gateway. On the engineering side, a multi-layer assurance system is built around continuous-integration gates, golden contract cases and six-way intent reconciliation: the key envelope supports rotation and revocation, local state is stored in five shards with legacy migration and partial-merge capability, shared front-end code is generated from a single source and gate-checked, runtime errors are observable through a diagnostic ring buffer and exportable, and every change must pass seventeen automated checks and the unit-test suite without regression, with the same gates exercised in continuous integration, where three environment-specific defects were found and fixed. The application is delivered as a pure front-end artifact without any back-end service, and is also published as version-matched Windows and Android installers, providing a feasible low-cost solution for the popularization of personal self-study tools.

**Keywords:** knowledge debt; knowledge graph; optical character recognition; constrained agent; spaced repetition

## 1 引　言

</div>

### 1.1 选题背景与意义

随着数字教育资源的高速增长，大学生与职业考证人群的自学材料大量以扫描版 PDF 形式存在，文本无法复制、章节结构混乱，学习者普遍面临"抓不住知识骨架、复习无重点、刷题后不知道错在哪"三类痛点。市面上的学习类应用多依赖人工录入题库或要求特定版式教材，对长尾教材的覆盖成本高、适应性差。

本设计提出以"知识债"为核心概念的自学辅导方案：将教材解析为知识图谱，把学习者尚未掌握且牵连后续知识的概念关系定义为"知识债"，以可解释算法定位债边并生成间隔修复计划，使复习从"盲目通读"转变为"按债修复"。其意义在于：其一，以纯前端形态实现教材级 OCR 与图谱构建，个人学习者零成本可用；其二，全部诊断数字由本地公式计算，规避了智能学习产品普遍存在的"算法黑箱"问题；其三，引入大语言模型但不赋予其改写数字的权限，兼顾智能化与可解释性。

### 1.2 国内外研究现状

在文字识别方面，Tesseract 引擎[5]经谷歌持续维护已成为开源 OCR 的事实标准，WebAssembly 技术[12]使其能够以近原生性能运行于浏览器；pdf.js 提供了文本层的程序化提取能力，两者结合构成"文本层优先、图像识别兜底"的通用解析路径。在知识抽取方面，TextRank[4]通过图排序实现无监督关键词抽取，Church 与 Hanks 提出的点互信息[6]为共现词对提供了统计关联度量，二者为领域图谱的自动构建提供了成熟基线。

在学习科学方面，艾宾浩斯发现的遗忘规律[3]与 Roediger、Karpicke 证实的测试效应[11]共同支撑了"间隔重复"与"以测代学"的方法论。在智能体方面，基于大语言模型的自主智能体[8]在规划与工具调用上展现出强大能力，但存在数字幻觉与越权风险，受约束智能体设计由此成为工程落地关键。现有学习类产品较少同时具备"教材级解析、可解释诊断、受约束智能"三项能力，这构成了本设计的切入点。

### 1.3 主要研究内容

本设计属于软件设计类课题，主要研究内容包括七个方面：一是教材与试卷文档解析流水线设计，覆盖文本层提取、扫描版判定、OCR 引擎阶梯，以及 PPT、Word、HTML、Markdown、TXT、EPUB 多格式导入与试卷、作业、错题的直拍识别；二是知识图谱与知识债算法设计，包括概念抽取、先修关系挖掘、试卷知识点层级图谱、影响分诊断与间隔修复计划；三是受约束智能体设计，包括口语化意图路由、危机干预与输出脱敏；四是大语言模型的受控集成设计，包括通用调用层、业务模块集成（增强构图、清洗、建议、出题与修复计划编排）与无密钥演示模式。五是教师协作与学习体验设计，包括面向教师的只读学情视图（授权与 k-匿名约束）、学情报告导出与作业单文件互传，以及新手引导、术语词典与图谱显示优化等体验改进。六是 AI 可用性与响应体验设计，包括云端请求的并发编排与排队、流式输出（含推理思维链的实时呈现）、失败重试与快速降级，以及题池预热与过渡题自动替换机制。七是工程化保障设计，包括前端共享代码的单一来源与生成区管理、持续集成门禁、黄金契约用例（编排意图六方对拍、输出转义、状态分片迁移）、密钥信封轮换与吊销、本地状态分片存储、巨型文件拆分与运行期诊断，以及纯前端形态与工程化形态之间的同源维护与持续集成实测验证。成果要求方面，本设计交付可运行的单文件应用、离线引擎资源、算法参数表与操作演示材料，并发布版本一致的 Windows 与 Android 安装包。

### 2.1 知识债与间隔重复理论

"知识债"借喻软件工程中的技术债概念，指当前未掌握且对未来学习构成利息的知识缺口，其特殊性在于缺口之间具备先修依赖关系，低层缺口会抬高后续知识的掌握成本。间隔重复理论源于艾宾浩斯的记忆保持实验[3]，其核心结论是记忆保持率随时间呈指数衰减，而在临近遗忘时进行复习可显著拉长保持周期。本设计将二者结合：以先修关系图为"债网"，按影响分排序修复顺序，以零、二、六天的间隔偏移安排三遍复习，实现按遗忘规律组织的个性化修复路径。

### 2.2 光学字符识别与 WebAssembly

光学字符识别（Optical Character Recognition，简称 OCR）将图像中的文字转换为机器可读文本。Tesseract 引擎[5]支持长短时记忆识别内核与多语言模型，本设计采用其中文简体与英文混合模型。WebAssembly[12]是一种可移植的二进制指令格式，允许将 C++ 编译的原生代码安全地运行于浏览器沙箱，为 OCR 的纯前端执行提供了载体；其 SIMD 子集可进一步提升识别吞吐。

### 2.3 大语言模型与受约束智能体

大语言模型（Large Language Model，简称 LLM）[7]具备自然语言理解、生成与简单推理能力，但在数值事实与结构化输出上存在幻觉风险。受约束智能体[8]通过意图路由、工具调用与输出过滤三层机制，将模型能力限制在预设边界内。本设计遵循"数字只由本地公式计算、模型只负责语言层任务"的约束原则，并以 Web 密码学套件对用户密钥进行高级加密标准（Advanced Encryption Standard，简称 AES）加密存储[9]。

面向首次使用的学习者，本设计补齐三类引导与减负措施。其一是新手帮助中心：首次进入自动给出三步上手说明（导入资料、查看识网、开始任务），并附可随时唤起的术语词典，覆盖知识债、红边、先修、影响分与销账等核心概念。其二是知债空态行动：当尚无红边时，页面解释红边出现条件，并提供「去练三道题（自动开始）」与「载入演示诊断」两条一键路径，后者注入标记为演示数据的错答记录以即时演示红边生成过程，并可一键清除。其三是持久化与显示精简：对话历史在本地留存并支持回放与清空；知识图谱提供「精简/完整」显示开关，默认按权重抽稀为节点数的一点六倍（不少于二十四条）并始终保留全部债务相关边，仅影响绘制而不影响诊断计算。

### 4.1 知识图谱自动构建

知识图谱以章节节点、术语节点与三类边（先修、共现、锚定）构成。构建流程分为三步。第一步章节识别，通过页式目录、行级标记与句子聚合三条路径提取章节结构。第二步概念抽取，采用 TextRank 算法[4]对句子构建共现图并迭代排序，同时以章节位置加权与领域词典过滤碎片词。第三步关系构建：先修关系由句式规则挖掘；共现关系采用点互信息度量[6]，见公式（4-1）所示。

PMI(x,y) = log₂ [ p(x,y) / ( p(x)·p(y) ) ]　　（4-1）

式（4-1）中，p(x,y) 为词 x 与词 y 在滑动窗口内的共现概率；p(x)、p(y) 分别为两词的独立出现概率。共现边按点互信息得分排序，低于阈值的边被丢弃。最后以 Kahn 拓扑排序去除先修关系中的环路，保证债网可传播。

### 4.2 学习诊断与修复计划算法

掌握度综合经验正确率、遗忘衰减与先修支撑三类信号，见公式（4-2）所示。

M = 0.5·acc + 0.3·exp(-Δt/S) + 0.2·min(sup, 1)　　（4-2）

式（4-2）中，acc 为该知识点近十次作答的正确率；Δt 为距上次作答的天数；S 为记忆强度，由连续达标次数与作答频次共同决定；sup 为先修节点的掌握度支撑度。影响分用于度量一条先修边的修复价值，见公式（4-3）所示。

I = base·σ(Δm₁)·σ(Δm₂)·w·c·f　　（4-3）

式（4-3）中，base 为目标节点的基础权重；σ(Δm₁)、σ(Δm₂) 分别为两端掌握度差的sigmoid衰减因子；w 为边权；c 为跨章系数；f 为作答频次因子。修复计划按影响分降序选取债边，以零、二、六天的偏移安排三遍复习，单日预算不超过四十分钟，计划条目的原因字段必须包含先修知识点名称，形成可校验的生成合约。销账判定要求连续两次达标且累计作答不少于三次，综合达标分为正确率与信心的加权和。

在上述生成合约的基础上，修复计划进一步扩展为五项可校验约束：K1 单日时长预算（默认四十分钟）、K2 先修有序（先修任务不晚于对应目标任务）、K3 任务说明必须包含先修知识点名称、K4 同一知识点任务间隔不少于一天、K5 开放债边至少被覆盖或被显式延期。计划由逐日容量调度器生成：任务按先修深度与影响分排序，逐条放置时实时校验每日容量与知识点间隔；生成后由合约引擎全量复核并自动修复违规项（时长压缩、任务顺延、说明回填与先修顺序调整），确保落库计划全部通过校验，排期之外的债边以显式延期注明。

### 4.3 OCR 引擎阶梯与单文件内联

解析流水线遵循"文本层优先"原则：先以双引擎提取 PDF 文本层，当可读字符低于动态门槛或乱码密集时判定为扫描版并转入识别阶梯。识别阶梯依次为宿主桥（本地脚本配合系统识别器）与浏览器内识别引擎，最终回退至手动粘贴。浏览器内识别引擎按采样策略选取待识别页，采用四阶段流水线将渲染、预处理、编码与识别重叠执行，并以页级置信度驱动低置信页的高倍率重识别。

为适配仅托管单个网页文件的平台，引擎采用全栈内联设计：识别工作线程与神经网络计算核心以二进制大对象地址装载，语言模型经压缩后以字节数组随页面携带，运行期零外部请求。该设计使约十八兆字节的自包含页面在手机浏览器中即可完成扫描教材的完整识别。此外，识别引擎提供图像直拍识别入口：照片、截图与画布图像经等比缩放与预处理后走同一识别阶梯，试卷、作业与错题的拍照导入由此获得与扫描页一致的识别质量。

### 4.4 意图路由与受约束智能体

智能体采用规则、轻量神经网络与模糊锚点三级意图路由：规则表以关键词锚点精确命中；轻量分类模型补强口语化表达；模糊锚点以子序列覆盖率做二次确认。危机类意图具有最高优先级，命中后立即输出心理援助转介话术且不可被其他分支覆盖。输出侧设置敏感词拦截，身份证号、银行卡密码等内容一律以提示语替代。全部评估数字仅由本地公式产生，模型回答若引用数字只能复述工具结果，实现"算法可解释、模型不越权"。在讲解层面，模型不受教材片段限制，可结合通用知识与可选的联网检索结果作答，教材之外的内容以【拓展】标注，与教材冲突时以教材为准并指出差异。

### 4.5 试卷作业错题识别与多格式导入

面向试卷、作业与错题的导入需求，模块提供拍照、截图、图片粘贴与文件选择四类入口，识别所得文本统一进入结构化与构图流程。图像识别复用识别引擎的预处理与工作线程池：照片、截图与画布图像先等比缩放至长边不超过二千六百像素，经极性归一与对比度拉伸后送识别，空白图像按墨迹覆盖率跳过，低置信结果以三倍率重识别后返回。

文档解析覆盖 PDF、Word、PPT、EPUB、HTML、Markdown 与 TXT：新版 Office 格式与 EPUB 均为 ZIP 容器，模块以纯脚本方式解析容器目录与解压（优先解压原始流，失败回退标准解压），再按格式提取正文——Word 依段落与标题样式还原层级，PPT 按幻灯片顺序提取正文与备注，EPUB 依阅读顺序展开正文，HTML 与 Markdown 经去标签与实体解码转为纯文本；旧版二进制 Office 文档按文本游程尽力提取并如实标注为尽力模式。当文档正文过短时，模块自动收集内嵌图片调用识别引擎补偿，使图文混排的讲义获得可用文本。各类型的导入方式与解析路径见表 4-1 所示。

识别或解析所得文本经确定性规则完成试卷结构化：先识别板块与题型分区，再切分题头、选项与答案，答案行支持“1.A 2.C”形式的批量分发，题型按题干特征推断为选择、填空、判断与解答四类，单卷题目上限三百。知识点图谱采用三层结构：主题层优先取教材章节，知识点层由教材词库按长词优先与位置不重叠策略匹配（单题上限四个），题目层保留题干与题型；边分四类——知识点对主题的归属、题目对知识点的考查、同题共现的知识点关联与继承自教材的先修关系，构图后按拓扑序清除回边。结构化与构图全部在本地确定性完成，不依赖模型；无教材词库时以试卷自身的词频与共现抽取兜底。图谱以分层方式渲染，点击节点可查看归属与考查明细，并可跳转识网定位或向智能体提问。

### 5.1 通用模型调用层与容错解析

应用在模型接入层实现了统一的消息补全接口，支持流式与非流式两种返回、可配置的令牌上限、温度参数与超时控制，并以并发闸控制并行度：至多两路请求同时执行，其余按先进先出排队，后台任务与用户主动操作互不阻塞。针对结构化任务，设计了容错解析函数：依次尝试直接解析、剥离代码围栏后解析与截取首尾括号后解析，三段均失败则返回空值并触发调用方回退。密钥管理采用信封加密：明文密钥经 AES 加密后存入本地存储，数据密钥为不可导出的密码学密钥并存于浏览器索引数据库，二者分离降低了密钥泄露风险。信封格式随后升级至第二版，增加版本号、密钥标识与指纹三类字段，并支持轮换与吊销：轮换后旧信封标记失效并按吊销清单校验，前端账户页对已吊销或已轮换的密钥即时提示重新配置，升级过程不影响其余主流程。

### 5.2 三模块集成设计

大语言模型深度参与三个业务模块。其一，图谱增强构图：模型依据章节目录与已有术语抽取概念集合与先修关系集合，经同名去重后合并入图，新增内容以独立来源标记，合并后统一清环并重建全部派生结构；重建时题池中已生成的模型命题完整保留、仅重建本地规则题，保证构图操作不影响练习进度与题目连续性。其二，识别文本清洗：识别完成后按页标记为界分块纠错，仅修正形近字、错误断行与标点，采用块级长度比与整体可读字数双重保护抑制幻觉，越界即保留原文。

其三，个性化建议与智能出题。建议模块基于当日快照生成两至三条可执行建议并按自然日缓存。出题模块为默认命题路径：命题依据不再局限于节点摘要，而由知识点正文、所在章节全文与全书目录共同构成约三千六百字的上下文，从源头保证题目主体有据可依，同时允许模型结合学科知识适度拓展命题，超出教材的考点在解析中标注【拓展】，兼顾依据性与区分度；考查层级按概念理解、因果分析、对比辨析、应用场景、错误辨析五类轮换，覆盖由记忆到分析的不同认知维度；答案支持下标与字母双形态并做范围钳制，题干经归一化去重后写入题池（上限三百题），解析失败自动回退本地规则法。默认策略上，练习加载时优先展示题池中的模型命题，池内无题则以全文上下文实时命题并明确提示生成状态，本地规则题仅作为离线兜底；今日任务直接以当日计划知识点为命题对象，当日新增或更新的教材会在命题上下文中标注优先覆盖，从而生成当日专属练习。

### 5.3 无密钥演示模式

考虑到评审与新用户通常不会自行配置模型密钥，应用内置了演示密钥：密钥以 AES-256-GCM 密文形式随文件分发、运行时解密，明文不落文件，用户另行配置时自定义密钥优先。各处智能入口（含修复计划编排与债务解读）在密钥不可用或离线时由本地规则引擎按同一链路生成结果，界面以"演示模式"徽标与说明文字明确区分，从而在零配置可体验的同时保持诚实标注。该设计保证了功能的零配置可体验性，同时以诚实标注避免伪造大模型输出的误导。演示模式下的诊断与讲解回复进一步按知识点组织：从问题文本识别教材节点，结合掌握度、教材要点、先修链与下游规模给出建议，零配置时也可获得与教材内容对齐的回答。

### 5.4 修复计划编排与债务解读

修复计划的编排由受约束的大语言模型承担：模型接收四类上下文——教材目录与债边相关章节正文、学习者画像摘要（薄弱点、错题集中度与销账进度）、当日学习快照以及债边事实清单，输出结构化的计划草案（总体策略、任务条目、执行提示与延期说明）。为抑制模型幻觉并保证计划质量，草案不直接落库：任何条目引用的知识点名称必须通过本地白名单校验，随后由合约引擎执行 K1–K5 全量校验与自动修复（时长压缩、任务顺延、说明回填与先修顺序调整）；修复后仍不合规的草案自动回退为本地规则生成的计划，模型调用失败、离线或未配置密钥时同样回退，主流程不被阻塞。

### 5.5 AI 可用性与响应体验设计

AI 能力的可用性由三层机制共同保障。其一是请求编排：云端调用设置并发闸，最多允许两路并行，其余请求按先进先出排队等待，后台任务与用户主动操作不再相互拒绝，从机制上消除了并发导致的静默降级。其二是故障隔离：仅传输类故障触发短暂冷却，冷却时间由三十秒缩短为八秒，期间由本地规则引擎或题库立即兜底，功能不中断。其三是密钥保障：内置演示密钥在用户未配置时自动启用，离线或密钥失效时整体降级为本地链路，界面始终如实标注输出来源。

响应体验方面，全部云端调用均采用流式输出。推理型模型在输出正式正文前通常存在较长的思维链过程，本设计将思维链一并收集并实时滚动呈现，使学习者在提问后约二点六秒即可看到"正在思考"的动态内容，而不是长时间面对空白；正文到达后按打字机方式增量刷新，命题类任务同步展示思考过程与草稿片段，建议类任务在生成期间显示占位提示，从而把不可压缩的模型推理时间转化为可见的过程反馈。

针对出题链路在不更换模型前提下耗时较长的固有约束，本设计采用题池预热与过渡题替换相结合的策略：题池为空时先以毫秒级速度呈现题库过渡题并明确标注，云端新题在后台生成完成后，若用户尚未作答则自动替换，若已作答则新题入池供下一次切换时秒出；生成结果若解析失败或与题池重复，则自动重试一次；过渡题上的命题状态提示在云端返回或学习者作答后立即清除，不随数据持久化残留。

实测表明，练习首题在零点二秒内呈现，AI 新题约十九秒完成替换，思考反馈在二点六秒内可见，全流程无运行期错误；上述指标已在全真实云端链路上端到端复验确认，AI 增强构图合并后题池中的模型命题亦完整保留。

与计划编排配套，模块为每条红色债边生成学生视角的债务解读，按“现状—拖累对象—建议动作”的结构组织语言，帮助学习者理解“先补什么、为什么”。全部解读按自然日缓存，原始数值仅在“公式详情”中展示；模型只参与叙述语言的组织，掌握度、影响分等评估数字仍由本地公式计算，AI 不改写任何数字。

本设计成果包括：可运行的单文件应用与离线引擎资源、算法参数表与工具清单（见附录 A、附录 B）、编排蓝图与操作演示材料。应用已部署于单文件托管平台，可通过移动浏览器直接访问验证；在纯前端形态之外，本设计同时提供与本应用版本一致的 Windows 与 Android 安装包（版本 2.6.0），面向桌面与移动场景分发，安装后离线可用；安装包以版本标签经 GitHub Release 公开发布，随版本演进持续更新。

### 6.4 工程化保障与质量验证

随着单文件应用与多端安装包并行演进，工程化保障成为质量维护的关键。本设计将前端共享代码（转义、归一化、拓扑排序、容错解析与本地状态存储五个模块）收敛至单一来源目录，页面内的共享代码由脚本生成并标注生成区边界，手工改动生成区将被构建校验拒绝；一键构建脚本按刷新生成区、三端镜像同步、哈希报告的顺序执行，单文件产物以基线校验和准入，未同步基线的改动无法合入。

契约层面为三类高风险逻辑建立黄金用例。其一，编排意图表与页面脚本、双端实现、集成脚本等六方来源逐条对拍，二十六个编排意图全部一致；其二，输出转义用例覆盖十四种跨站脚本注入形态，断言转义后标记失活；其三，本地状态分片用例覆盖旧键迁移、损坏分片、配额回退等十种场景，其中包含同毫秒备份键碰撞与可解析但非对象内容两类真实缺陷的回归用例。静态门禁方面，全部脚本改动经解析级检查（只解析不执行），一百八十一个 C# 源文件不允许出现空捕获块，密钥信封轮换与吊销另有八项单元测试。

密钥与状态的可靠性由专门机制保证。密钥信封升级至第二版后支持轮换与吊销，轮换后的旧信封即时失效并在前端账户页提示重新配置；本地状态按元数据、教材、作答、计划、试卷五类分片存储，写入时仅持久化发生变化的分片，旧版单键数据在首次启动时自动迁移并留底，残缺分片自动合并，配额不足时先清理备份再强制全写重试，迁移与恢复路径均经真实浏览器环境冒烟验证。

代码结构与运行期可观测性同步改善。行数近五百行的意图路由器按职责拆分为模式集、角色、意图、叙事组装与默认意图表五个文件，主文件行数下降约四成；后端诊断以环形缓冲记录运行事件并经就绪接口暴露，前端采集错误与未处理拒绝各五十条并支持一键导出，使纯前端应用的线上问题排查有迹可循。

上述机制全部纳入持续集成流水线：每次提交自动执行十七项自动化校验（覆盖意图对拍、转义黄金用例、分片用例、生成区检查、命名规范与单文件基线）与三百二十九项单元测试。最近一轮全量验收结果为十七项校验全部通过、单元测试零回归，单文件产物体积 18 187 662 字节，三端镜像哈希一致。

上述保障在纯前端形态与工程化形态之间保持同源。工程化形态（含 Windows 壳、Android 壳与后端服务）完成加固后，改造内容反向移植回纯前端源目录，两者的页面基座与自包含单文件产物逐字节一致，差异只体现在宿主与后端部分。纯前端形态因此在不做功能取舍的前提下共享了同一套保障，交付形态之间的能力差异被压缩到只剩运行环境。

持续集成在无人值守环境中的首次运行暴露了三处只在该环境出现的问题：OCR 宿主定位语言包目录时的兜底路径未做存在性检查，运行时控制台编码导致中文校验输出中断，共享内核生成块的比对未归一行尾。三处修复后流水线恢复全绿，单次运行约三分半钟。这说明门禁不仅在本地有效，在真实运行环境中的暴露能力同样可靠。

## 7 商业模式与应用前景

### 7.1 商业模式

本应用采取"免费获客、生态变现"的四层模式。第一层为免费个人学习版，即本设计的交付形态，以零成本建立用户规模；第二层为平台技能资产，将教育算法能力封装为编排技能，按平台机制获得调用分成；第三层为校园机构授权，面向高校与培训机构提供批量解析与学情看板，按席位收取年费；第四层为内容生态合作，与出版社共建正版结构化教材包。个人版采用用户自带密钥模式，本项目不垫付模型成本，使免费层可持续。

### 7.2 应用前景

近期可服务于高校期末冲刺与考研自学场景；中期可扩展至职业资格考试领域，其知识体系高度结构化，与知识债模型天然契合，机构学情看板构成商业切入点；远期可与出版机构共建正版内容生态，编排技能亦可为其他教育类应用复用，形成从工具到平台资产的放大路径。

本设计完成了从教材解析、知识图谱构建、学习诊断到智能陪伴的全链路实现，主要工作与结论如下：其一，实现了浏览器端教材级识别，单文件内联设计使扫描版教材的离线结构化成为可能；其二，以三类可解释公式支撑学习诊断，避免了智能学习产品的算法黑箱问题；其三，大语言模型在受约束框架下深度参与图谱、清洗、出题与修复计划编排，并以演示模式实现零配置体验；其四，试卷、作业与错题的直拍识别与 PPT、Word、HTML、Markdown、TXT、EPUB 多格式导入使应用从教材学习延伸至练习诊断场景，识别结果自动结构化并生成知识点层级图谱；其五，从普通用户视角完成了系统性体验改进，并落地面向教师的只读学情视图、学情报告与作业单文件互传，使应用在无服务端的约束下仍具备教学协作的最小闭环。其六，在不更换模型的前提下，通过并发编排、流式输出、题池预热与失败重试等工程手段，使 AI 能力在并发、弱网与故障条件下均保持可用且响应迅速。其七，建立了以自动化门禁与黄金用例为核心的工程质量保障体系，前端共享代码由单一来源生成、密钥信封可轮换可吊销、本地状态分片可迁移可恢复、运行期错误可观测导出，全部变更须经十七项自动化校验与三百二十九项单元测试确认无回归后方可合入；该门禁已在持续集成环境中实跑通过，并据其反馈修复了三处环境相关的缺陷。本设计仍存在局限：长尾学科领域词典覆盖不足，识别引擎对公式与代码的准确率有限，模型增强效果依赖用户网络与密钥配置。后续工作将围绕学科词典扩展、版面分析增强与端侧小型模型引入三个方向展开。

### A.1 识别引擎参数

　　识别倍率 2.0，低置信页重试倍率 3.0；置信阈值 65，空白页墨迹覆盖率阈值 0.4%；渲染长边上限 2600 像素，逐页声明分辨率 72×倍率；桌面端双工作线程。内联装载：工作线程与计算核心以二进制大对象地址提供，语言模型经压缩后字节数组内嵌。图像识别复用同一组参数与工作线程池，输入支持照片、截图与画布图像，等比缩放长边上限 2600 像素，空白图像按墨迹覆盖率跳过。

### A.2 智能参与参数

　　识别清洗：分块 1800 字符（页标记优先定界），预算十二块，温度 0.1，单块超时 30 秒，幻觉保护为块级长度比 0.7～1.6 与整体可读字数 0.9。增强构图：概念八至十五个、先修五至十二条，温度 0.3，超时 60 秒，合并去重键为归一化标题。智能出题：四选一结构，答案下标与字母双形态钳制，温度 0.6，题池上限三百。学习建议：不超过一百二十字，温度 0.5，超时 25 秒，自然日缓存。云端并发上限二路、传输类故障冷却八秒；智能出题预算一千五百令牌与六十秒、学习建议八百令牌与三十五秒；全部调用采用流式输出并实时呈现思维链。密钥信封：第二版格式含版本号、密钥标识与指纹，支持轮换与吊销，前端账户页对失效信封即时提示。本地状态分片：元数据、教材、作答、计划、试卷五类，写入仅持久化变化分片；旧版单键首次启动自动迁移并留底，残缺分片自动合并，配额不足时先清理备份再强制全写。运行期诊断：前端环形缓冲保留最近五十条记录，支持一键导出；后端诊断事件经就绪接口暴露。

### A.3 试卷结构化与层级图谱参数

　　试卷结构化单卷题目上限三百；选项支持同行内联与独立行两种版式，答案分发采用编号匹配与顺序兜底；题型推断为选择、填空、判断与解答四类。层级图谱节点分主题、知识点与题目三层，单卷题目节点上限一百二十；知识点匹配为长词优先且位置不重叠，单题上限四个；边分归属、考查、同题共现与先修四类，构图后按拓扑序清除回边。图谱显示层另提供「精简/完整」切换：精简模式按节点数约 1.6 倍（不低于 24 条）保留权重最高的边，并始终保留全部债务相关边，仅影响绘制、不影响诊断计算。
