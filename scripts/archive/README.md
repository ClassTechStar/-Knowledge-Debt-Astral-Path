# scripts/archive —— 一次性代码补丁脚本（已归档）

本目录存放项目演进期使用过的**一次性源码改写脚本**（`patch_*.py`）。
它们直接对 `src/` 下的源文件做字符串替换，**不属于构建或运行链路**，
也不应再次执行（源码已包含其效果，重复执行会污染文件）。

归档原因：这些脚本位于 `scripts/` 根目录时容易被误认为常规工具，造成误跑风险；
保留而非删除是为了留存变更历史与审计线索。

| 脚本 | 用途（历史） |
|---|---|
| `patch_graph_switch.py` | 图谱切换相关 UI/接口补丁 |
| `patch_graph_visual.py` | 图谱可视化补丁 |
| `patch_plan_teacher.py` | 计划与教师端补丁 |
| `patch_ui_auth.py` | 界面与账户补丁 |

> 新的一致性/维护脚本请写在 `scripts/` 根目录，例如 `naming_consistency.py`（命名一致性检查）。
